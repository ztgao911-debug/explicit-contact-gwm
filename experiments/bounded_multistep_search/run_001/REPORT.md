## 冻结协议与训练路径

沿用同一45324参数网络、空间编码、归一化、接触几何、解析力参数、数据划分与ROI。每支路上限固定为16 mm和1.6 m/s。训练池固定为中央普通600帧对、已有108中央分支及90初始响应对；左侧普通轨迹和18分支仅做开发验证，右侧不参与搜索。

A在五个端点前逐帧读取真实当前状态，B只在起点初始化并五步自回归，C在B上加网格惩罚。三组共享相同五端点、普通绝对监督和初始响应监督。其余9组在固定池无放回生成，候选清单先于正式训练保存。

专用训练路径保留x/v、重算状态特征、距离核与网络更新的梯度；MuJoCo查询读取预测状态的detached副本，返回接触量停止梯度。因此是条件梯度近似，不是穿过求解器全程可微。位置和端点瞬时速度独立监督。

实际五步梯度预检：末端损失对第一步位置／速度梯度范数分别为 **4.69394 / 0.198579**；固定节点严格约束，未执行优化器更新。无接触时沿用原零接触上下文，内部状态特征仍保留梯度。

展开项按所有监督端点求平均。网格项为mean(relu(0.1−V/V_rest)²)，0.1是训练惩罚阈值，物理筛选中的翻转阈值则是V/V_rest≤0。中央原生数据已先检查通过，未根据左侧结果修改阈值。

每组最多2000更新、batch16；相同更新数不等于相同计算量。所有候选用同一30个五步AR窗口、固定位置／速度0.5权重、固定单位0.001 m／0.1 m/s及四阶段／两区域等权选模，包含第0步。选模不加候选网格项，不随训练速度权重改变。
