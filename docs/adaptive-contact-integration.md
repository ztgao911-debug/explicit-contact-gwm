## 方法与假设

原固定重心积分依靠采样点碰到接触区域。小区域靠近三角片边角时，
连续几何已经检出接触，却可能所有积分点都在区域外。
本轮先裁出积分域，再在内部采样，不设置最小面积或最小压力下限。

1. 从当前节点位置构造同一已知材料面，固定节点先恢复 rest / 零速度。
2. 对每个面片求到球心的最近材料点。只有严格正穿透的面片参与积分；
   精确相切按固定浮点舍入带处理，不人为扩大接触。
3. 将三角片分成以最近点为共同顶点的扇形三角域，各域内部互不重复。
4. 从已位于球内的顶点发射射线，解析求球面交点，截断到原有界三角域。
   Gauss 节点位于裁剪域内部，即使是微小角点区域，也有正权重和正穿透。
5. 对裁剪域自适应积分，比较不同阶数的面积、弹性和阻尼估计。

积分仍使用原先的径向压力基底：

```text
D = sphere_radius + skin
delta(q) = max(D - ||q-c||, 0)
normal(q) = (q-c)/||q-c||
I_elastic = ∫ delta(q) normal(q) dA                    # m³
I_damping = ∫ max(v_rel(q)·normal(q), 0) normal(q) dA    # m³/s
```

射线参数 s 的面积 Jacobian 含 s；裁剪到出口 s_max 后，权重含 `s_max²*u`。
共享边和顶点为零面积，不按重复候选数量累加点弹簧力。
法向力矩使用 `(robot_center - origin) × I_elastic`，与在材料点积分径向法向力矩一致。
参考点为当前活动质量质心，不执行固定软块的自由刚体更新。

材料速度仍按当前节点瞬时速度插值，不求移动最近点的速度，也不使用位移 / dt。
沿射线，材料速度为线性函数，法向接近速度的分子为二次多项式。
实现显式在其变号根处切开阻尼积分，避免在错误方向上反复细分。
弹性部分保持与速度无关的积分表达式，单测确认其对节点速度的梯度为零。

## 精度设置与独立参照

种子 7，CPU 单线程，float64。
阶数固定为 **4 / 8 / 16 / 32**，相对容差 **1e-4**，
面积 / 弹性 / 阻尼绝对容差分别为 **1e-18 m² / 1e-26 m³ / 1e-22 m³/s**。
最大细分深度 12、每次查询递归区间预算 512。
预算耗尽保留估计并标记未收敛，不丢弃面片或强制改成零。
这些是数值设置，不是按左侧得分选择的模型超参数。

独立参照采用另一种算法：材料面映射到平面，求圆盘与三角片的交区，
按竖直切片积分；内层弹性积分使用解析原函数，外层分别用 128 / 256 阶 Gauss。
预测器不读取参照函数。两阶用于检查参照自身稳定性，也不能称为物理求解器真值。

参照覆盖全部 **48 个静态例子**、预定轨迹第 **70 / 110 / 150** 帧（共 15 状态），
以及全部 **24 个额外微小区域例子**，共 87 次参照场景。
没有根据结果另挑位置，右侧数组未加载，左侧不是未触碰的盲测。

## 实测三：平面闭式结果

顶面中心接触圆位于有限软块顶面内部。
球心到平面高度 `h=D-depth`，压头向下速度 u=0.01 m/s，材料静止：

```text
area = π(D²-h²)
I_elastic,z = -π h * depth²
I_damping,z = -2π u h² log(D/h)
```

| 压入 μm | 面积相对误差 | 弹性相对误差 | 阻尼相对误差 |
| --- | ---: | ---: | ---: |
| 50 | 0.001225% | **0.002451%** | 0.001223% |
| 100 | 0.000232% | 0.000463% | 0.000228% |
| 500 | 0.0000877% | 0.000175% | 0.0000863% |
| 1000 | 0.0000544% | 0.000109% | 0.0000473% |

## 局限：17 个阻尼局部判据标记

正式运行的“所有局部积分判据通过”为 **false**，没有重写为 true。
中央 8 帧、左侧 9 帧各有一个阻尼区间达到最大深度，未满足该区间的局部判据；
没有触发 512 区间预算上限。案例在 `trajectory_unresolved_cases.csv`。

出现具体问题后，逐例增加分量诊断，没有再搜索阶数 / 容差：

- 17 例的面积与弹性局部失败数均为 **0**，失败均为阻尼分量。
- 对每例，合计面积 / 弹性 / 阻尼的**误差估计**都在同一全局容差内，
  最差误差估计 / 容差比约 **0.3853**。
- 这不是严格误差证明，也不撤销原局部标记。
- 诊断重算与已保存积分向量逐位相同，未更换样本或前向结果。

因此可说明**正面积漏积分已修复，面积 / 弹性检查通过**；
不能宣称所有阻尼积分都已通过局部收敛验收。
