## 修正方法与表示假设

上一轮的 6914 个小球即使足够密，球并集仍有凹缝和球面法向。
本轮保持球形压头半径 **12 mm**、皮肤厚度 **1 mm**、
140 个动力学节点、35 个固定节点、代理绑定与密度、数据划分不变。
不扩大球半径，不添加经过验证集调整的接触 margin，不继续搜索密度。

利用已知初始三角连接，把当前 Gaussian 中心连接成 **216 个有边界的线性面片**。
这些面片的 110 个角点来自已有角点 Gaussian；当前物理皮肤仍是 1 mm 米制偏移。
6914 个代理绑定保留，但同一原三角片内部的重心细分不改变连续线性面，
所以查询直接用角点求解，内部增密点对此分支是冗余的。
这项假设变化必须与“只修改球并集的公式”区分。

输入仅为当前节点位置 / 瞬时速度、当前球心 / 速度和球半径。
先恢复固定节点位置与零速度，再插值代理。初始连接关系固定，
不读取 MuJoCo 的当前面、接触、力、未来软体状态或未来压头输入。

对每个有界三角片，使用 PyTorch Voronoi 区域解析计算最近点，显式处理面内、边和角点。
设球心为 `c`，材料面最近点为 `q`，则：

```text
gap = ||q-c|| - R - skin
normal = (q-c)/||q-c||              # 压头 → 软体
contact_point = ((q-skin*normal) + (c+R*normal))/2
material_velocity = Σ barycentric_i * current_node_velocity_i
relative_velocity = current_robot_velocity - material_velocity
```

法向与距离来自同一个最近点，不把无限平面投影当作物体边缘之外的真实表面，
不硬编码向下法向。接触点速度是**材料瞬时速度插值**，
不是最近点随压头滑动的速度，也没有用位移 / dt 冒充速度。
非退化片内部，距离对球心的梯度应为 `-normal`；实测最大不一致约 **2.22e-16**。

使用条件：球心位于材料外部、面片非退化、已知拓扑有效。
球心落在材料面上或面片退化会显式报错；没有验证破裂、翻面或无拓扑重建。
最近面片切换处导数为分段形式，不声称全局光滑。

精确相切时设置固定 IEEE 舍入带：`8*eps(dtype)*(R+skin)`。
本轮 float64 为 **2.309e-17 m**，不是可调的物理接触 margin；原始间隙不修改。
单测验证 ±1e-12 m 的真实分离 / 压入仍可区分。

## 两种输出与公平评价

模块 `ContinuousContactSurface.query` 返回：

- `contacts`：全局最近接触点，最多一个，用于单球的最近距离 / 法向查询。
- `face_candidates`：全部发生接触的面片候选，单独保存；不能直接各算一份弹簧力相加。
- 最近片编号、重心权重、材料点与瞬时速度，支持后续明确接触位置口径。

`object_indices` 仍是代理锚点编号，不是力应全部施加到的单个动力学节点。
后续正式载荷分配需要面片 / 重心映射与面积权重，不能只使用该锚点。

为避免“只留一个点看起来法向更好”的混淆，同时评价：

1. **相同最近点协议**：两方法各取一个最近代表点，与其最近的原生候选比较。
   包括原球并集漏检的真接触帧，最近代表点仍可用于诊断。
2. **完整候选集合协议**：保留旧点集合指标，对全部面片候选评分，
   同时报告候选数与共同检出帧。
3. 保留上一轮最早的 **14 个共同帧**，以及增密后的 **172 个共同帧**，
   不用改变帧集合制造改善。

## 实测：法向、接触点与候选覆盖

同一 **172 个左侧共同检出帧**，与原生当前几何比较：

| 协议 / 输出 | 点误差 mm | 法向误差 ° |
| --- | ---: | ---: |
| 增密球：一个最近代表点 | 0.45904 | 2.20145 |
| 连续面：一个最近代表点 | 4.65e-9 | 1.49e-8 |
| 增密球：完整候选集合 | 0.69737 | 3.85422 |
| 连续面：完整面片候选 | **4.84e-9** | **3.42e-8** |
| 连续面：仅一个点，按完整集合口径评分 | **1.61815** | 1.49e-8 |

最近代表点误差是到最近原生候选的距离；集合点误差是对称最近邻平均。
最后一行点覆盖明显退化，说明**一个准确最近点并不等于完整接触分布**。
因此后续力实验不能只把 `contacts` 的一个点当成全部接触区域。
完整面片候选也改善，才支持“并非仅靠减少点数降低法向均值”的结论。

上一轮更早的同一 **14 帧**，完整候选点误差为
**0.42260 mm → 1.33e-8 mm**，法向 **2.25588° → 4.07e-8°**。
不把角度接近零解释为材料模型或网络预测接近完美。

左侧全部 **183 个真接触帧**，完整面片候选点误差 **5.11e-9 mm**，
法向 **4.00e-8°**。已有轨迹中，面片候选与原生候选数逐帧相同：
中央共 619、左侧共 576 个，每帧最多 6 个。

**候选流形策略仍有边界。** 原静态扫描中，5634 次查询有 **934 次**候选数量不同；
接触 / 分离判定并未不同。不能从这五条轨迹推广为所有边角情形的候选集合等价。
`verification.json` 同时保留数量不一致，不删去这些静态查询。
3756 个正压入静态查询上，完整面片集合的点误差均值 / 最大值为
**0.1221 / 1.8539 mm**，法向为 **1.1862 / 18.0959°**；这项残余不能隐藏。
同批静态查询的**最近代表点**法向误差均值 / 最大值约
**2.84e-6 / 5.54e-4°**，与连续网格参照的最大夹角约 **1.21e-6°**。
因此最近距离 / 法向查询正确，不意味着所有静态面片候选都与原生接触流形等价。
完整候选聚合与边角冗余处理仍需下一轮检验。

## 速度口径与后续力比较

独立复核中，材料点与瞬时材料速度均严格等于当前节点的重心插值，误差为零。
但它与既有原生适配器的相对速度向量 RMSE 约 **0.666 mm/s**。
既有适配器在接触中点按四面体 / 截断权重插值，本分支在材料面最近点插值，
取点和插值口径存在差异。

这是两个接触速度构造方式的差异，**不是下一帧速度预测误差**；本轮没有预测下一帧。
下一轮解析阻尼 / 摩擦力比较应先统一或明确这个口径，
不能看到位置 / 法向一致便宣称全部接触输入相同。

## 下一步与复现

下一优先项是**在该拓扑辅助分支上统一接触速度口径，检验解析力的面积权重 / 聚合与密度依赖**。
