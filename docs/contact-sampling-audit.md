## 检查范围与目的

140 个动力学节点、35 个固定节点和 6914 个 Gaussian 代理绑定保留。
三类检查分别回答：

1. 速度差是否只是取点 / 插值方式不同，是否能与当前材料点运动学一致。
2. 同一材料点的多个候选是否被重复计力，去重能解决什么、不能解决什么。
3. 改用当前表面积分后，结果是否随固定积分分辨率收敛，是否仍漏掉微小接触区域。

中央浅 / 深、左侧浅 / 深和无接触五条轨迹，各当前帧 0–299，共 **1500 帧**。
候选聚合另复查原 **5634 次静态查询**。

另固定每个区域前 3 个特征位置（顶面、侧 / 底面、边、角，共 12 个），
各查询分离 50 μm、压入 50 / 500 / 1000 μm，共 **48 个**静态例子，增加 n=64 参考。

## 一：统一“哪个材料点的瞬时速度”

旧适配器在接触**中点**上按四面体求权重、截断并归一化。
新连续面分支在材料面最近点上按三角片重心插值。
两种口径不相同，不能把其差异称为下一帧速度预测错误。

原生查询新增显式选项：

```python
native.query(state, robot, with_force=False,
             velocity_mode="material_surface")
```

默认仍为 `legacy_midpoint_tetra`，复现历史行为。
本轮所有查询中，默认和显式旧模式逐位相同；新旧模式的位置、法向、间隙和索引也逐位相同。
仅返回给解析力 / 网络的相对速度条件不同，没有修改原生状态或原生求力过程。

在压头指向软体的法向 n 下，从原生碰撞中点恢复材料点：

```text
q_material = contact_midpoint + (skin + gap/2) * normal
v_material = Σ barycentric_i(q_material) * current_node_velocity_i
v_relative = current_robot_velocity - v_material
```

恢复点经当前已知表面投影消除 CCD 舍入误差，固定节点先恢复 rest / 零速度。
这里是固定材料坐标的瞬时速度，不是最近点随压头滑动的速度，也不是位移 / dt。
当前压头只有三个平移自由度；未来旋转工具还需明确角速度项。

速度比较只在两方接触点距离 ≤**10 nm** 的相同几何候选上配对。
这是配对阈值，不是接触 margin。左侧全部 576 个候选均配对；
中央 619 个中配对 608 个，另 11 个几何未匹配候选明确保留在统计表中。
全部帧的候选 / 接触与力变化指标没有据此删除。

相对速度向量 RMSE，单位 **mm/s**：

| 数据 / 阶段 | 配对候选数 | 旧口径与连续面之差 | 统一材料点后的差 |
| --- | ---: | ---: | ---: |
| 中央全部 | 608 | 0.59977 | 1.98e-8 |
| 左侧全部 | 576 | **0.69160** | **1.63e-8** |
| 左侧按压 | 346 | 0.61031 | 9.18e-9 |
| 左侧保持 | 162 | 0.01927 | 4.14e-10 |
| 左侧释放 | 68 | 1.46813 | 4.27e-8 |

接近 / 恢复 / 无接触对照没有接触候选，接触速度 RMSE 不适用，不记成成功的零误差。
左侧旧差异的法向 / 切向 RMS 为 **0.67933 / 0.12966 mm/s**。
上一轮约 0.666 mm/s 是中央与左侧合并、最近候选的另一统计口径，不能与左侧单独数值混比。

独立检查预定第 70 / 110 / 150 帧，共五轨迹 × 3 = **15 个当前状态**：
用 MuJoCo 节点位置 Jacobian × 当前 qvel，再按同一材料重心权重组合。
材料点速度与压头速度的最大绝对差均为 **0 m/s**。
这验证所选材料点运动学，不意味着原生约束求解器内部的接触 Jacobian 定义已逐项复现。

复用旧中央标定参数 `k=691.386733 N/m, c=0 N·s/m, tangent=4 N·s/m, μ=0.3`，
只替换速度条件，左侧全帧合力**变化**的 RMS 约 **0.488 mN**。
这是输入口径变化对冻结旧力模型的影响，**不是相对真值的力误差下降**。

## 二：材料点去重检查

新增分组保留代表候选、原成员 / 面片编号和重数。
只有以下条件同时满足才合并：同一拓扑材料支撑、重心权重一致，
位置、法向、间隙、速度也在固定数值容差内一致。
不会把空间上重合但属于不连通材料的两个面合并，也不平均不同的速度 / 法向。

容差预先固定：位置 **1 nm**、重心权重 **1e-10**、速度 **1e-9 m/s**；
不是为了拟合原生候选数量而搜索的阈值。

| 查询区域 | 原面片候选总数 | 材料点分组后 | 删除重复记录 |
| --- | ---: | ---: | ---: |
| 中央轨迹 | 619 | 614 | 5 |
| 左侧轨迹 | 576 | 571 | 5 |
| 全部静态查询 | 14572 | 9382 | 5190 |

重复点会重复贡献旧点弹簧力，单测直接验证两份完全相同记录会产生两倍合力。
但本批普通轨迹重复点很少：左侧去重造成冻结旧模型合力变化 RMS 约 **0.191 mN**。
不能把所有力模型误差都归因于这 5 个重复记录。

**去重没有解决原生流形差异。** 静态查询中，原面片候选数与原生候选数不一致为
934 次；对两方按相同材料点规则分组后，不一致为 **1268 次**。
角点的不一致从 24 次降至 0，但边、顶面与侧面的结果没有同步改善。
普通轨迹分组后，中央和左侧也各有 1 帧数量不一致。

原生 CCD 的点位置 / 材料支撑有数值近似，候选裁剪策略也不同。
本轮未放宽材料权重容差去强行匹配数量。
几何接触检测在分组前后保留；去重只是去除重复材料记录，
**既不是接触面积模型，也不保证复现原生候选集合。**

## 三：用面积积分检查密度依赖

新增三角面重心积分：每个原面细分 n² 个子三角形，每个取一个重心，
权重为**当前**子三角形面积。面内部各有唯一归属；共享边 / 顶点的面积为零。
重复材料面的输入被拒绝，原动力学节点和 Gaussian 数量不增加。

在材料样本 s 上定义球形压头的米制穿透与径向接触法向：

```text
delta(s) = max(R + skin - ||s-c||, 0)
n(s) = (s-c)/||s-c||
I_elastic = ∫ delta(s) n(s) dA                       # m³
I_damping = ∫ max(v_relative(s)·n(s), 0) n(s) dA      # m³/s，仅接触区域
```

若之后采用压力弹簧模型，面积刚度单位应为 **N/m³**，阻尼为 **N·s/m³**。
旧的每候选刚度 **N/m** 不能无修改地乘这个面积积分。
杨氏模量也没有直接当作接触刚度。
法向力矩积分基底单位为 m⁴，参考点为当前活动质量质心；
没有把合力转换成固定软块的自由刚体更新。
新积分只检查法向弹性 / 阻尼基底，尚未建立标定后的面积摩擦模型。

左侧同一 600 帧：

| 细分 n | 把旧 k 复制到每个积分点：合力 RMS，N | 面积弹性向量积分 RMS，10⁻⁹ m³ | 与 n=32 的相对向量 L2 差 | 真接触却无积分点帧 |
| --- | ---: | ---: | ---: | ---: |
| 4 | 0.2061 | 0.98672 | 10.547% | 9 |
| 8 | 0.7756 | 0.93047 | 1.692% | 3 |
| 16 | 3.0846 | 0.92550 | **0.337%** | 2 |
| 32 | 12.3160 | 0.92388 | 参考自身，非真值 | 0 |

每面的采样数增加 64 倍，复制旧刚度的诊断合力增加 **59.75 倍**。
这是重复逐点计力的反例，不是这些 N 数值经过了新的物理标定。
面积积分随分辨率逐渐稳定；n=32 仍只是较细数值参照，不能称作真值。
中央 n=4 / 8 / 16 的相对差为 **11.305% / 1.377% / 0.267%**，
真接触却无积分点的帧为 **21 / 12 / 4 / 0**（最后一项 n=32）。

## 独立平面解析检查

用静止顶面中心，压入 100 / 500 / 1000 μm，球形压头的接触圆完全位于顶面内部。
设 `D=R+skin`、球心到平面高度 `h=D-depth`，当前径向压力定义下：

```text
接触面积 = π(D²-h²)
I_elastic,z = -π h * depth²
```

与该闭式结果比较，法向积分的相对误差：

| n | 100 μm | 500 μm | 1000 μm |
| --- | ---: | ---: | ---: |
| 4 | 28.924% | 4.286% | 2.345% |
| 8 | 2.170% | 0.205% | 0.326% |
| 16 | 0.323% | 0.194% | 0.0478% |
| 32 | 0.236% | 0.00910% | 0.01052% |
| 64 | 0.01318% | 0.00168% | 0.00190% |

这是几何积分一致性检查，不是 MuJoCo 合力拟合成绩。

## 尚未解决：边角微小接触面积

48 个固定静态例子给出重要反例：即使 n=64，仍有 **3 个浅角点接触**
被连续几何检出，但固定重心积分没有采到正穿透点，积分为零。
边缘同类问题在 n=32 仍有 3 个，到 n=64 才消失。

在角点穿透严格为正、面非退化的情况下，连续性保证其附近有正面积接触区域。
因此这个零是**有限积分漏采**，不能解释成没有接触或没有作用区域。
接触检测必须继续使用连续面距离，不能改用“正穿透积分点数量”。

角点 n=32 相对 n=64 的整体 L2 差仅约 **0.746%**，
但 n=64 自身仍漏掉上述 3 个小区域；这说明总体收敛分数不能替代逐案例的正性检查。
没有继续增大 n 去搜索更好数字，也没有删除这些例子。
失败例子保存在 `selected_static_zero_integral_contact_cases.csv`，
程序异常与数值漏采分别由 `failures.json` 和 `limitations.json` 记录。
