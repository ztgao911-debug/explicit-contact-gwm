# 自主恢复与位置—瞬时速度联合预测

2026-10-26，已在当前 Mac / CPU 实际完成。结果目录：
`outputs/joint_state_recovery/run_001/`。

后续已完成[邻域信息与容量对照消融](neighbor-recovery-ablation.md)。本页的自主模型在新实验中作为 A
逐位复现；新增邻域均值未带来稳定动力学优势，完整负结果另见新记录。

**自主分支显著减少无接触漂移，但尚未正确复现弹性振动。**
左侧验证全部窗口的 20 步活动节点位置误差比恒速下降 49.54%，速度误差下降 29.13%；
按压、保持预测退化，恢复窗口的速度误差也有退化。不能把本轮称为“已解决弹性恢复”。

## 本轮改动及目的

1. 直接保留当前静止坐标、形变和速度，让无接触时的内部运动有可用输入。
   旧接触编码器在没有接触时会返回全零；新内部支路不依赖这段零上下文。
2. 增加不受接触门控关闭的内部支路；外部接触支路继续受门控控制。
3. 联合监督位移残差和真实瞬时速度增量，不再由位移反推出端点瞬时速度。
4. 加入同容量的门控对照，区分自主恢复分支的作用和联合速度监督、训练帧增加带来的变化。

新实现为 `src/contact_gwm/joint_state_dynamics.py`，入口为 `scripts/train_joint_state.py`，
配置 `configs/train_joint_state.yaml`，评价模块 `scripts/joint_state_evaluation.py`。
原实现、冻结 B 权重、全部数据和既有输出均保留。

## 模型与离散状态定义

设内部支路输出位置残差 / 速度增量 `(r_x_internal, dv_internal)`，
接触支路输出 `(r_x_contact, dv_contact)`：

```text
自主模型：
  dx = current_v * dt + r_x_internal + gate * r_x_contact
  dv = dv_internal + gate * dv_contact

同容量门控对照：
  dx = current_v * dt + gate * (r_x_internal + r_x_contact)
  dv = gate * (dv_internal + dv_contact)

共同更新：
  x_next = x + dx
  v_next = v + dv
  固定节点：x_next=rest，v_next=0，dx=dv=0
```

`dt=0.01 s`。`dv` 的监督是保存的两个瞬时速度之差；`dx` 的监督是相邻位置之差。
**速度变量的定义与监督已修正，速度预测精度仍须检验。**
这是学习有限时间的离散状态映射，不强制帧间恒加速度，不保证连续时间的力学一致性、
能量守恒或非穿透，也不宣称可以更换 dt 直接使用。

内部支路输入为原 10 维当前状态特征和固定 18 维静止坐标编码；
接触支路为原 36 维接触上下文加同样的固定编码。两支路均为两层宽 128 的 SiLU MLP，六维输出头。
静止编码频率仍为 `{0.5,1,2}`，没有搜索频率或使用可训练节点嵌入。
内部原始输出采用 `f(current_features)-f(rest_features_with_zero_displacement_velocity)`，
使静止形状、零速度、无接触时保持内部平衡；这不是对一般运动的能量稳定性保证。

每支路经 tanh 限制：位置残差单轴上限 0.001 m，速度增量单轴上限 0.1 m/s。
两支路相加后的总上限可为上述的两倍，未额外裁剪状态。
速度输出尺度仅按中央训练标签确定：中央最大绝对速度增量约 0.081279 m/s，
最大位置残差 `|dx-v*dt|` 约 315.252 μm。没有据左侧成绩调整上限。

| 方法 | 可训练参数 | 本轮训练覆盖 | 无接触时行为 |
| --- | ---: | --- | --- |
| 恒速 CV | 0 | 无 | 保持当前瞬时速度 |
| `frozen_legacy` | 24326（本轮冻结） | 历史中央固定 8 帧对 | 接触门控关闭后等于 CV |
| `gated_joint` | 45324 | 中央全部 600 帧对 | 两支路都关闭，等于 CV（存在极小 float32 舍入差） |
| `autonomous_joint` | 45324 | 同上 | 内部支路继续工作 |

两新模型分别从头训练，共用逐项相同的初始参数和同一 minibatch 顺序，
只有内部支路的门控规则不同。旧 B 训练覆盖和容量不同，只作为历史对照，
不能将相对旧 B 的全部提升归因于新架构。

## 数据、接触条件与选模

中央两条各 300 对用于训练，左侧两条共 600 对用于验证，另 300 对无接触对照只用于评价。
右侧测试数组未加载；保护原文件的 SHA256 检查会读取它们的文件字节，但不使用数组标签。
全部阶段均保留，包括阶段交界帧和没有接触的帧。
中央 600 对中，184 对存在受力接触、416 对无受力接触；释放无接触 87 对、恢复观察无接触 200 对。

本轮固定使用 **MuJoCo 当前几何＋原生真实力条件**，暂不重新比较解析力与高斯几何。
训练和推理均从当前节点位置、速度及当前外部压头状态重建 MuJoCo，保留所有 gap≤0 的几何候选；
不再按真实力阈值筛选网络接触输入。真实力只作为本轮声明的调试条件。
下一帧位置 / 速度仅进入监督；下一帧接触、力、动作不用于构造输入。

种子 7，CPU 单线程，每组 **2000 次更新**，每批 16 帧对，Adam 学习率 0.001，
余弦衰减至 1%，梯度裁剪阈值 1。公共损失：

```text
Lx = 0.5*MSE_active((dx_pred-dx_true)/0.001)
   + 0.5*MSE_neighborhood((dx_pred-dx_true)/0.001)
Lv = 0.5*MSE_active((dv_pred-dv_true)/0.1)
   + 0.5*MSE_neighborhood((dv_pred-dv_true)/0.1)
selection_loss = 0.5*Lx + 0.5*Lv
backward_loss = 100*selection_loss
```

这里 MSE 按 XYZ 坐标平均，邻域分母为 `3*节点帧数`；两量的单位分别为 m、m/s。
两个归一化单位相差 dt。每 50 步评价完整训练 / 验证集合，第 0 步参加选模；
只按左侧完整单步联合损失选择权重，选定后才执行 rollout，未根据 rollout 重新选权重。

| 新模型 | 所选步数 | 最低验证联合损失 | 第 2000 步验证损失 |
| --- | ---: | ---: | ---: |
| gated | 200 | 2.09850e-4 | 3.13466e-4 |
| autonomous | 100 | 1.71578e-4 | 7.56161e-4 |

自主模型第 2000 步验证损失是所选值的 **4.41 倍**，而训练损失继续降低。
这是明确的训练 / 验证分化，不支持简单延长训练。下面全部预测使用已选检查点，而非第 2000 步参数。

## 实测单步结果

各方法使用共同掩码：105 个活动节点，35 个底部固定节点；
接触邻域沿用上轮半径 0.02 m 的参考 ROI，无接触后沿用最后 ROI，首次接触前使用静止顶面 ROI。
ROI 仅用于损失 / 评分，不进入网络。指标为 XYZ 向量 RMSE，按节点帧 SSE 汇总后开根号。

左侧全部 600 对，位置是**位移增量误差 μm**，速度是**下一时刻瞬时速度误差 mm/s**：

| 方法 | 活动增量 | 活动速度 | 邻域增量 | 邻域速度 |
| --- | ---: | ---: | ---: | ---: |
| CV | 15.537 | 2.755 | 20.048 | 3.422 |
| 冻结旧 B | 16.986 | 3.094 | 23.754 | 4.320 |
| gated | 15.418 | 2.739 | 19.709 | 3.379 |
| autonomous | **14.236** | **2.401** | **18.406** | **3.067** |

自主模型全阶段活动位置 / 速度误差相对 CV 降低 **8.38% / 12.85%**，
相对同容量 gated 降低 **7.67% / 12.35%**。全部无接触帧中，
自主模型活动增量 / 速度为 14.680 μm / 2.482 mm/s，CV 为 16.411 / 2.977。

阶段不能混在一起概括。左侧活动节点各格为 **增量 μm / 速度 mm/s**：

| 阶段 | CV | gated | autonomous |
| --- | ---: | ---: | ---: |
| 按压 | 4.651 / 0.864 | 5.142 / 0.892 | 6.252 / 1.174 |
| 保持 | 1.657 / 0.315 | 2.786 / 0.444 | 5.256 / 1.036 |
| 释放 | 32.206 / 5.633 | 31.791 / 5.584 | 28.796 / 4.757 |
| 恢复观察 | 9.371 / 1.802 | 9.371 / 1.802 | 8.714 / 1.569 |

按压、保持两项都退化。保持时外部力与内部恢复应平衡，但当前模型仍产生错误运动。
“支路不再关闭”已经实现，“有接触时平衡、无接触时正确振动”尚未实现。
全部阶段的两区域结果、旧模型及逐轨迹指标见 `one_step_metrics.csv`、`one_step_per_trajectory.csv`。

## 实测短时 rollout

仍为**给定实际压头轨迹的软体自回归预测**。起点固定为 70、110、140、150、170、210，
每条轨迹六个窗口，每种方法共 30 个窗口，均完整预测 20 步。
初始化后没有真实软体位置、速度、接触或力回填；原生接触从预测状态重新求解。
全部方法使用同一初始 ROI 和窗口；本次没有失败窗口。

左侧全部 12 个窗口汇总，各格为 **活动位置 μm / 活动速度 mm/s**：

| 方法 | 5 步 | 10 步 | 20 步 |
| --- | ---: | ---: | ---: |
| CV | 154.742 / 5.077 | 362.816 / 7.403 | 895.152 / 5.769 |
| 冻结旧 B | 209.152 / 6.053 | 457.738 / 7.189 | 1011.849 / 6.703 |
| gated | 154.157 / 4.960 | 345.424 / 6.891 | 817.971 / 5.811 |
| autonomous | **123.873 / 4.319** | **251.192 / 5.288** | **451.678 / 4.089** |

20 步自主模型活动位置 / 速度相对 CV 下降 **49.54% / 29.13%**，
相对 gated 下降 **44.78% / 29.65%**。20 步接触邻域为 **859.865 μm / 6.160 mm/s**，
CV 为 1477.100 / 9.237，分别改善 41.79% / 33.31%。

但 5 步接触邻域位置 **207.551 μm**，差于 CV 的 **185.013 μm**；
10 步邻域位置 **463.450 μm**，也略差于 gated 的 **463.060 μm**。
下面按起始阶段拆分 20 步活动区域，防止总体分数掩盖失败：

| 起始阶段 | CV 位置 / 速度 | gated 位置 / 速度 | autonomous 位置 / 速度 |
| --- | ---: | ---: | ---: |
| 按压 | 230.501 / 1.765 | 550.335 / 3.770 | 514.541 / 2.577 |
| 保持 | 69.734 / 0.341 | 358.566 / 2.674 | 410.055 / 1.795 |
| 释放（3 个起点 / 轨迹） | 1208.513 / 7.972 | 1035.172 / 7.648 | 512.705 / 5.268 |
| 恢复观察 | 606.857 / 2.411 | 606.857 / 2.411 | 50.834 / 2.681 |

恢复窗口位置大幅改善，**速度误差却比 CV 高约 11.16%**；不是所有阶段都同时改善。

## 恢复机制学到了什么

left_deep 从第 170 帧预测至第 190 帧，真实与全部预测均无接触：

| 20 步末状态 | 真实 | CV / gated | autonomous |
| --- | ---: | ---: | ---: |
| 相对静止形状的 RMS 形变 μm | 42.400 | 1169.631 | 92.574 |
| RMS 瞬时速度 mm/s | 3.580 | 5.767 | 0.379 |

自主模型压住了弹道漂移，但速度低估约 **89.4%**，并停留在错误形变上。
第 210 帧窗口也一样：真实末速度 3.112 mm/s、预测仅 0.243 mm/s。
实测曲线表现为振动被过度平滑、速度快速衰减，不能把低位置误差解释为正确的弹性恢复。

针对这一具体问题，额外读取已保存的预测，对静止顶面、压头 XY 下方最近的固定编号节点 **31**
作有符号 z 位移 / 瞬时 vz 检查，未改权重或重新选模。
在 `|vz|>0.01 mm/s` 的样本中统计符号变化：170 起点真实 11 次，自主 1 次；
210 起点真实 7 次，自主 2 次；CV、旧模型和 gated 均为 0 次。
这是离散代表节点诊断，不是连续频率或能量测量。
210 窗末端该探针真实 z 形变为 -6.381 μm，CV 为 -21.800 μm，自主为 +27.571 μm，
**该探针的自主末端位移误差反而更大**，没有将总体改善概括为所有节点改善。
CSV 和有符号曲线保存在 `analysis/`，入口为 `scripts/analyze_joint_recovery.py`。

![分阶段形变与速度](../outputs/joint_state_recovery/run_001/left_deep_deformation_speed_windows.png)

**解释与尚未验证的假设**：当前内部网络逐节点读取自身形变与速度，没有读取邻居的当前相对形变、
相对速度，因此未显式描述网格内应变耦合。它可能更容易学到平均速度抑制，而非正确恢复振动。
接触支路与内部支路的力学平衡也没有结构约束。这些是解释候选，当前实验没有证明唯一因果来源。
本轮没有用结果改变网络、数据或选模规则，也没有开展三组接触条件的新比较。

**下一步唯一优先项：修正自主恢复分支的振动与速度动力学。**
建议先在现有固定脱离接触窗口上，检验加入静态网格邻居的当前相对形变、相对速度是否改善相位与幅度，
同时保留保持阶段作为退化检查。邻域耦合的收益尚待独立对照验证；暂不扩大数据或调整高斯接触几何。

## 实际检查与复现

- 完整运行 **68.64 s**；两组训练分别 21.96 s、22.56 s，其余为缓存、评价、重载与绘图。
- 当前输出约 **54.82 MB**（后续分析 / 验证小文件另计）。环境沿用 Python 3.13.5、
  PyTorch 2.14.1、MuJoCo 3.3.7、macOS arm64，CPU 单线程。
- **61 个 pytest 通过**，包含新增 13 项；Ruff 全仓库通过。
- 固定节点位置 / 速度 / 增量误差全部为 0；非有限值、rollout 异常、四面体翻转均为 0。
- 两组梯度有限、未触发梯度裁剪；保存重载后 20 步预测逐位一致。
- 预测 NPZ 重载有限且稳定节点编号一致；未来状态与全部保存接触 / 力标签置 NaN 不改变当前网络输入。
- 新模型临时场景测试也验证了初始化后标签污染不影响 rollout。
- 原有 **361 个**数据 / 结果文件 SHA256 保持不变；静止无接触对照 20 步位置误差约 3.17e-10 μm。


本轮仍是一个固定种子、小规模数据、验证选模下的管线实验，不能据此声称稳定跨位置泛化、
正确连续时间力学或无接触恢复问题已解决。
