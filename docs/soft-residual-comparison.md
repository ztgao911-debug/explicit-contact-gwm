# 恒速残差模型与完整轨迹划分比较

日期：2026-10-15（Asia/Shanghai）。本轮已实际运行两种网络的 CPU 训练、验证选模、
测试集评估及保存后独立重评。结论是：**本轮残差网络未超过恒速基线**。
结果和权重均保留，没有依据测试结果重新调整模型或超参数。

仍然提供真实当前状态与当前 MuJoCo 接触、力作为条件，执行相邻记录帧的一步预测；
没有自由多步运行，也没有从视觉或 Gaussian 几何推断接触。

## 模型与公平比较协议

每个节点对应一个 Gaussian，尺度、旋转、固定底部、输入和归一化沿用首次训练。
140 个节点中，105 个为活动节点、35 个底部节点固定。
模型仅预测中心增量，`dt=0.01 s`，绕过自由刚体更新。

| 方法 | 预测总增量 |
| --- | --- |
| 静止基线 | `0` |
| 恒速基线 | `v[t] × dt` |
| 直接位移网络 | `gate[t] × MLP(current_inputs)` |
| 恒速残差网络 | `v[t] × dt + gate[t] × MLP(current_inputs)` |

四种方法的底部总增量均通过硬掩码设为零，恒速项也受此约束。
两种网络均为原两层 128 维 SiLU MLP，**参数数目均为 22022**，输出层从零初始化，
门控 sigma 为 0.02 m，学习输出的单轴 tanh 限幅为 0.001 m。
残差零初始化恰好等于恒速预测。
无接触时学习残差为零，总增量仍保留活动节点的恒速项。

输入仍为初始位置、当前形变、当前节点速度、固定标记、当前目标 / 实际压头状态，
以及当前 MuJoCo 接触点、法向、距离和力；未输入下一帧状态或接触力。
归一化常数保持不变，不用测试集或未来标签拟合归一化统计。
目标仍是 `x[t+1]−x[t]`，先以 float64 相减再转 float32。
恒速项直接读取当前记录的瞬时节点速度，没有用相邻位置差构造速度。

`configs/compare_soft_residual.yaml` 继承原 `configs/train_soft_local.yaml`，
保存运行目录中的 `config.yaml` 为完全展开的配置。
原直接位移类、训练脚本、配置和原有 `outputs/soft_local_training/run_001/` 结果保留。
为保证比较使用同一选模协议，本轮另行从零训练直接位移网络，不直接拿上轮训练损失选出的权重比较。

## 完整轨迹划分与帧选择

| 集合 | 完整轨迹 | 按压帧对 | 保持帧对 | 总帧对 |
| --- | --- | --- | --- | --- |
| 训练 | center_shallow、center_deep | 71 | 78 | 149 |
| 验证 | left_shallow、left_deep | 71 | 78 | 149 |
| 测试 | right_shallow、right_deep | 71 | 78 | 149 |

每组浅轨迹为 71 对（32 按压、39 保持），深轨迹为 78 对（39 按压、39 保持）。
三组轨迹名无交集，没有随机拆帧。
帧对仍要求当前存在 `distance<=0` 且受力大于 `1e−8 N` 的接触，
当前与下一帧的协议阶段均在按压 / 保持中。阶段仅用于筛选，不进入模型。
无接触对照及释放 / 恢复阶段不参与这次性能评估，无接触残差性质通过单独测试检查。

## 验证选模与测试时序

每种网络训练 500 epoch，Adam 初始学习率 0.001，余弦衰减到 1%，批量 16，种子 7，CPU 单线程。
两种网络使用相同初始网络随机种子和同一独立随机数种子生成的批次顺序。
损失仍为活动节点和接触邻域坐标 MSE 各 0.5，误差除以 0.001 m 后计算。

选择指标预先固定为 **左侧验证集的相同加权坐标 MSE**；取最低值，平局保留更早 epoch。
包含 epoch 0：直接模型此时为静止预测，残差模型此时为恒速预测。
验证前向处于 `no_grad()`，不回传梯度；训练函数只接收训练和验证数据包。

| 网络 | 验证选中的 epoch | 最低验证损失 | 训练及逐 epoch 评估耗时 |
| --- | --- | --- | --- |
| 直接位移 | **381** | 0.000024378693 | 26.39 s |
| 恒速残差 | **137** | 0.000006541889 | 26.94 s |

残差初始恒速候选的验证损失约为 0.00000689586；验证集选择了有学习修正的 epoch 137。
更晚 epoch 的训练损失继续降低，验证损失反而增大，因此没有使用最后的 epoch 500 作为残差测试权重。

两种权重选定并写盘后，先写 `selection_locked.json`，保存 epoch、配置及检查点 SHA-256，
再加载右侧测试轨迹的数组进行评估。
锁文件中 `test_arrays_loaded=false` 描述写锁时刻；总报告另记录测试加载发生在锁定之后。
测试结果没有参与选模、早停或学习率调整。

## 指标定义与实测结果

指标是三维中心**增量向量 RMSE**：
`sqrt(mean(||delta_pred−delta_true||²))`，单位 mm，越小越好。
活动节点统计包含所有非固定节点，不按真实位移大小删选。
接触邻域沿用当前帧中心到有效接触点三维距离不超过 0.02 m 的规则，排除固定节点。
四种方法在每个集合上使用完全相同的帧对、目标和节点掩码。

下面均为验证集选定的权重，不是各集合分别挑选的最优权重。

| 方法 | 训练活动 | 训练邻域 | 验证活动 | 验证邻域 | 测试活动 | 测试邻域 |
| --- | --- | --- | --- | --- | --- | --- |
| 静止 | 0.021301 | 0.033815 | 0.022551 | 0.038626 | 0.023029 | 0.038631 |
| 恒速 | **0.003771** | 0.003572 | 0.004294 | 0.004789 | **0.004226** | **0.004710** |
| 直接位移网络 | 0.004469 | **0.003510** | 0.007521 | 0.009471 | 0.007069 | 0.008786 |
| 恒速残差网络 | 0.003793 | 0.003634 | **0.004224** | **0.004627** | 0.004551 | 0.005424 |

残差模型在验证集上略优于恒速，在测试集上活动节点误差比恒速高 **7.71%**，
接触邻域高 **15.15%**。本轮没有获得超越恒速的测试收益，不能将残差学习描述为成功提升预测精度。
训练行也使用验证选择的权重，因此不等于训练损失最低时的误差。

## 复现

当前环境依赖已具备。重评保存结果不会重新训练，也不会重新选模：

```bash
source .venv/bin/activate
python scripts/compare_soft_models.py --evaluate-only outputs/soft_residual_comparison/run_001
python -m pytest
```

从头复现到另一个目录，保留本次结果：

```bash
python scripts/compare_soft_models.py --output-dir outputs/soft_residual_comparison/run_002
```

新环境使用原项目的测试与绘图依赖即可，数据加载不要求重新安装求解器：

```bash
python -m pip install -e ".[dev,experiments]"
```

实测平台：Apple M1 / arm64、macOS 15.6.1、Python 3.13.5、PyTorch 2.14.1。
本批只有六条单材料轨迹，验证与测试各两个完整轨迹；没有重复种子或置信区间。
当前结果用于检验残差建模与选模流程，不能推断广泛场景的泛化能力。
真实当前状态和求解器接触条件持续提供，因此也不能解释为自由多步预测能力。
