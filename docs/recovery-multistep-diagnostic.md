## 目的与固定样本

上一轮邻域均值 B 未稳定优于 A、C，且恢复振动被过度抑制。
本轮保持 B 的结构，检查网络能否拟合一个固定恢复片段，以及五步联合监督是否改善递推。

窗口在运行前固定为 `center_deep` **第 210–230 帧**，即 2.10–2.30 s，
21 个状态、20 个相邻帧对，全部为恢复观察阶段，真实接触数为零。
只加载这一条轨迹和共享网格；不加载左侧、右侧或其他轨迹数组。
历史 B 的旧权重只作背景对照，两组新模型均从相同的未训练 B 参数开始。

具体步骤及目的：

1. 核对原始独立 MuJoCo 数据的 SHA256、稳定节点编号和 dt，保护已有结果。
2. 保持 B 的 46092 参数、静态邻域、归一化、输出上限及固定底部约束，隔离训练监督跨度。
3. 构造相同的重叠窗口与监督权重，避免五步组额外使用更多独立数据。
4. 实现可微递推，确保后续误差能通过预测位置、速度与邻域特征反向传播。
5. 同时评价单步、五步和更长的自由递推，检查位置误差之外的速度、振幅与换号。

入口：`scripts/diagnose_recovery_multistep.py`；配置：`configs/diagnose_recovery_multistep.yaml`；
可微递推：`src/contact_gwm/recovery_multistep.py`；后续只读分析：`scripts/analyze_recovery_multistep.py`。
已有模型、训练脚本、数据及历史结果均保留。

## 两组的公平性和选权重规则

从第 210–225 帧的 16 个起点各构造长度 5 的窗口，两组每次更新使用**完全相同的 80 个监督端点**。
这些端点有重叠，只对应 20 个独立帧对；中间帧比边缘帧出现得更多，但两组权重完全相同。

| 组 | 训练时的当前状态来源 | 监督标签 |
| --- | --- | --- |
| 一步组 `one_step` | 每步读取该步真实当前 x、瞬时 v，五次独立单步预测 | 同一批 80 个下一状态 |
| 五步组 `five_step` | 只在各窗口起点初始化，之后连续五步使用自身预测 | 同上 |

**两组在自由递推评价时都不回填软体真值。** 一步组训练中的 teacher forcing 是显式对照条件，
不能把它的五个独立预测称为训练时自回归。

种子 7，逐项相同的初始参数，B 内部宽度 128、接触分支宽度 128，dt=0.01 s。
保持 Adam、学习率 0.001、余弦衰减至 1%、2000 更新、梯度裁剪 1、损失乘 100。
每次更新全用 16 个窗口，不再随机抽帧；两组均计算 80 个状态预测。
相对上一轮全轨迹训练，样本范围和每次计算量已经改变，所以不把与历史 B 的差异全部归因于监督跨度。

保留原位置—瞬时速度联合损失：

```text
Lx = 0.5*MSE_active((x_pred-x_true)/0.001)
   + 0.5*MSE_ROI((x_pred-x_true)/0.001)
Lv = 0.5*MSE_active((v_pred-v_true)/0.1)
   + 0.5*MSE_ROI((v_pred-v_true)/0.1)
joint_loss = 0.5*Lx + 0.5*Lv
backward_loss = 100*joint_loss
```

MSE 按坐标平均，单位分别为 m、m/s。位置更新仍为 `x_next=x+dx`，
速度更新为 `v_next=v+dv`，没有用位移除以 dt 冒充端点瞬时速度。
评价活动节点 105 个；ROI 为原参考接触邻域在第 210 帧的固定掩码，共 20 个活动节点。
固定节点 35 个，每步位置设为 rest、速度及总增量设为零。

每 50 步记录两种拟合损失，含第 0 步；**两组统一按同一训练窗口的五步联合损失最低值保存权重**，
不读取验证 / 测试轨迹，不使用 20 步结果重新挑权重。
这是一种预先固定的共同诊断选取规则，使用了训练标签，不能称为验证选模。

## 无接触条件与可微实现

可微入口只接受模型、初始位置 / 速度、静止形状、固定掩码、归一化和步数，
没有目标数组或未来接触 / 力参数。邻域特征每步从当前预测状态重新计算，
步间没有 `.detach()` 或 NumPy 转换。

本轮针对已脱离接触的窗口，训练时采用零接触上下文和零接触门控，未对 MuJoCo 求导。
这不是回放未来真实接触：根据 B 的每轴位置残差上限 0.001 m 和速度增量上限 0.1 m/s，
对任意五步训练预测可给出保守节点 z 上界：

```text
max_z <= max(initial_z) + 5*max_rx + 5*dt*max(positive_initial_vz)
         + dt*max_dv*5*4/2 + rounding_margin
       = 0.0457137 m
```

已知压头底部减去 flex 碰撞皮肤的 z 为 0.055 m，仍有 **9.286 mm** 的垂直间隔。
因此所有可能的五步训练输出都无法碰到压头，不依赖预测后的真实接触标签来决定门控。
接触支路结构保留，但在零门控下梯度为零，参数实际检查保持初始值不变。
因此这两份从头拟合的权重仅供恢复诊断，接触支路未训练；
没有替换全轨迹模型，也没有验证它们的按压 / 保持预测能力。

更长的 20 步评价使用原始 `JointStatePipeline`，逐步从预测软体状态查询当前 MuJoCo 接触。
四种方法的全部 20 步均无接触；三个网络的可微无接触实现与原管线的 20 步结果**逐位一致**，
最大位置 / 速度差为零，排除了两套递推代码口径不一致造成当前现象。

| --- | ---: | ---: |
| 初始化 | 2.172148e-4 | 5.015053e-3 |
| 一步组 | 4.389385e-6 | **2.380120e-5** |
| 五步组 | 1.066197e-5 | 2.794520e-5 |

五步组在本预算下的公共五步损失反而比一步组高约 **17.41%**，没有全面拟合优势。
但两组相对初始化都大幅降低损失，不能再把失败概括为“B 完全无法拟合这个恢复片段”。

## 从第 210 帧自由递推 20 步

这是在同一个训练片段内、单一起点的自由预测；超过 5 步后，预测步长超过了训练监督跨度，
但目标时刻仍属于已用于训练的片段。**它不是未见数据或跨轨迹泛化。**

活动节点结果，各格为 **位置 μm / 速度 mm/s**：

| 方法 | 5 步 | 10 步 | 20 步 |
| --- | ---: | ---: | ---: |
| 恒速 | 229.919 / 9.227 | 537.252 / 2.871 | 1057.567 / 3.371 |
| 历史 B | 102.162 / 5.424 | 149.942 / 4.708 | 120.317 / **3.448** |
| 一步组 | **16.332 / 2.148** | 24.512 / 5.408 | 189.248 / 38.399 |
| 五步组 | 17.117 / **2.048** | **20.689 / 2.205** | **32.976 / 21.546** |

20 步 ROI 结果：恒速 **1152.234 / 3.177**，历史 B **132.192 / 3.592**，
一步组 **292.948 / 60.219**，五步组 **32.741 / 27.653**。
五步监督缓解了长预测的位置偏差，但 20 步速度误差仍明显差于恒速和历史 B。
不能只展示五步组的 32.976 μm 位置误差而忽略 21.546 mm/s 速度误差。

逐步曲线显示后段速度误差显著放大：五步组从第 10 步的 2.205 mm/s 增至第 20 步的 21.546 mm/s，
约 9.77 倍。第 20 步真实活动节点 RMS 速度为 **3.198 mm/s**，
一步组预测 **38.450 mm/s**、五步组 **21.684 mm/s**。
这些是有限片段的误差增长观察，不是 Jacobian 谱或 Lyapunov 指数的测量。

## 振动波形是否拟合

探针按静止顶面和初始压头 XY 预先确定，为中央顶面节点 **71**。
不是上一轮左侧轨迹的节点 31，也没有根据新误差挑选节点。

## 结论的边界与唯一后续优先项

1. **表达与优化不是完全失效**：同一 B 在固定小片段上可以拟合单步变化，也能跟随短时振动。
   但这没有证明它能表达所有恢复模式或适用于其他轨迹。
2. **五步监督收益不一致**：在固定预算下公共五步损失仍差于一步组；
   它改善了较长预测的部分指标，却没有消除 20 步速度误差放大。
3. 本轮没有更改接触几何、解析力、数据规模或渲染，因而不支持将新现象归因于这些因素。

**下一轮只优先做状态转移的递推稳定性诊断**：
在这个已拟合片段附近，对初始位置 / 速度施加可控小扰动，检查哪些误差方向随预测步数被放大，
再决定是否约束位置—速度状态转移或调整训练跨度。
当前曲线尚不能单独证明唯一根因或某个稳定化方案有效；不建议直接增加数据或进入渲染主线。
