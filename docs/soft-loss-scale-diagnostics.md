# 单帧残差损失数值尺度对照

日期：2026-10-15。本轮在原 CPU 环境中实际训练三组相同网络。
**损失乘 100 后，活动节点 RMSE 从 3.278 降到 2.848 μm，改善约 13.1%；
乘 10000 反而变差。损失尺度影响了优化，但尚未解决单帧强拟合不足。**

## 本轮检查的目的

上一轮确认单节点能拟合、梯度可传播，但共享网络同时拟合多个节点仍有误差。
本轮只放大损失数值，检查它是否会让隐藏层获得更有效的参数更新。
所有组都用原始物理单位的误差比较，避免把损失数值变化误当成预测质量变化。

## 严格保持的条件

配置入口为 `configs/diagnose_soft_loss_scale.yaml`，继承上一轮单帧诊断配置。

- 同一 `center_deep` 第 **71 帧**，相邻记录间隔 **0.01 s**。
  当前编码、速度、标签、门控、固定节点及邻域掩码均与上一轮保存内容逐项一致。
- 仅监督这一帧的 **105 个活动节点**，底部 **35 个节点**固定。
- 原两层 128 维 SiLU MLP、22022 个参数、零输出层、原归一化和 1000 μm 输出上限。
  三组初始参数 SHA-256 一致。
- 原 Adam 学习率 0.001、2000 次更新、余弦衰减至 1%、裁剪阈值 1、种子 7，
  `betas=(0.9, 0.999)`、`eps=1e-8` 均相同。
- 当前 MuJoCo 状态、接触和力作为调试输入；下一帧只构造监督标签。
  不加载左侧验证或右侧测试数组，不进行自由多步预测。

原公共目标记为 `canonical_loss`：

```text
0.5 × MSE_active((predicted_delta - true_delta) / 0.001)
+ 0.5 × MSE_neighborhood((predicted_delta - true_delta) / 0.001)
```

本轮只将反向传播的目标改为 `multiplier × canonical_loss`。
恒速项不含可训练参数，因此该误差也等于学习残差与真实恒速残差之差。
没有缩放物理标签、输入、输出上限或学习率，也没有改变两个区域的相对权重。

运行前固定三个倍数 **1、100、10000**，分别在数学上等价于损失单位
`0.001、0.0001、0.00001 m`。实现中保留原公共目标，显式乘倍数，便于统一比较。
没有在看到结果后继续搜索其他倍数。

每组均按当前训练帧的最低 **公共目标**保存权重，包含第 0 步，平局取更早步骤。
物理 RMSE、公共目标和放大后的目标分别记录；放大后的目标不用于跨组比较。

## 实测拟合结果

下表为三维增量向量 RMSE，单位 **μm**，不是单坐标 RMSE。
恒速基线为活动节点 **6.67322 μm**、接触邻域 **5.20222 μm**。

| 损失倍数 | 等效损失单位 m | 活动节点 RMSE | 接触邻域 RMSE | 活动节点相对恒速下降 | 触发裁剪次数 / 2000 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ×1，原设置 | 0.001 | 3.27798 | 1.37775 | 50.88% | 0 |
| ×100 | 0.0001 | **2.84802** | **1.33267** | **57.32%** | 0 |
| ×10000 | 0.00001 | 3.50198 | 1.51218 | 47.52% | 1377 |

相对原设置，×100 的活动节点误差降低约 **13.1%**、接触邻域误差降低约 **3.3%**。
三组最优公共目标分别为 `2.107224e-6、1.647869e-6、2.425089e-6`，均出现在第 2000 步。
各组训练与逐步评估耗时分别约 **2.44、2.41、2.32 s**。

**预期与实测**：若数值尺度是主要瓶颈，放大损失应显著改善同一帧拟合。
实测只有有限改善，三组都未达到上一轮预设的 **90% RMSE 降幅**强拟合标准。
因此不能把数值尺度称为已解决的唯一根因，也不能将本轮训练帧成绩称为泛化。

## 梯度是否变大，参数是否真的更新更多

代码逐步记录整个模型的裁剪前 / 后梯度范数、裁剪系数及实际参数变化，
并在第 1、2、10、100、500、1000、2000 步保存逐参数张量明细。
更新量直接由 `parameter_after - parameter_before` 测量，没有用 `learning_rate × gradient` 代替。
统计过程不改变参数、梯度或 Adam 状态。

同一初始化位置的第一次更新：

| 倍数 | 全模型裁剪前梯度 L2 | 裁剪后梯度 L2 | 实际全模型参数更新 L2 |
| --- | ---: | ---: | ---: |
| ×1 | 0.00081755 | 0.00081755 | 0.0196113 |
| ×100 | 0.08175495 | 0.08175495 | 0.0196714 |
| ×10000 | 8.175494 | 约 1 | 0.0196722 |

梯度随倍数增大，实际更新没有按相同比例增大。
Adam 的归一化和保留不变的裁剪阈值都会影响实际更新，不能仅凭梯度变大判断优化更好。

第一次更新时，零输出头使隐藏层梯度及更新仍为零；以下是**第二次更新**的第一隐藏层权重：

| 倍数 | 裁剪前梯度 L2 | 实际权重更新 L2 | 正二阶矩 RMS 中低于 `eps` 的比例 |
| --- | ---: | ---: | ---: |
| ×1 | 0.000016399 | 0.0278805 | 54.84% |
| ×100 | 0.00164217 | 0.0411849 | 12.47% |
| ×10000 | 0.164217 | 0.0437592 | 6.28% |

×100 的这一步第一层实际更新比原设置约大 **48%**；两个组均未触发裁剪。
二阶矩统计使用 Adam 保存的、经过偏差修正后的 RMS，仅统计非零项，
不是把本次瞬时梯度直接与 `eps` 比较。统计中的零矩项排除，避免将未使用分支算作受抑制项。

这些观测与原设置中部分小梯度项受到固定 `eps` 影响的解释一致，
但本轮没有单独改变 `eps`，不能将全部改善唯一归因于它。
×10000 虽然进一步改变数值比例，却频繁触发裁剪，最终误差更高；裁剪本身是保留的训练规则，
本轮没有为这一组另行调整阈值。

保存完整配置、同一帧编码 / 标签 / 节点编号、三组最优和最后权重、预测 NPZ、
逐步损失与更新 CSV、逐层参数更新和 Adam 数值统计、三张对比图、代码快照、摘要及哈希清单。

已实际检查：

- ×1 组的**全部 2001 个公共损失、选中步数、选中权重**与上一轮原单帧 Adam 结果精确一致，
  说明新增统计没有改变原训练结果。
- 三组初始参数及当前输入 / 标签相同，固定节点总增量为零，预测和梯度均有限。
- 保存后重新加载 3 组模型和 4 个 NPZ，预测和物理指标精确一致，选模匹配公共损失最小值；
  单独执行 `--verify-only` 再次通过。

- `python -m pytest`：**28 个测试通过，1.83 s**。新增检查覆盖初始梯度随倍数变化、

本轮只改变一个全局目标倍数，仍只观察一个帧、一个种子和相同训练预算。
没有扩大数据、训练多帧模型或使用验证 / 测试误差挑选倍数，也没有修改正式训练配置。
