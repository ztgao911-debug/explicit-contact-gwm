# 固定 8 帧对的空间编码消融

日期：2026-10-15。本轮已在当前 Mac / CPU 上实际训练 A、B、C 三组。
**B 的总体活动节点、接触邻域误差均优于 A，也优于参数量接近的 C；
但保持阶段活动节点误差退化，三组均未达到原小样本诊断标准。**
本轮只判断被训练样本上的拟合能力，没有验证未见帧或跨位置泛化。

## 实验目的与固定条件

本轮检查固定空间编码是否帮助原共享 MLP 表示不同节点的残差，
同时用加宽原 MLP 的 C 组检查增加参数量能否产生类似收益。
配置为 `configs/ablate_soft_spatial_encoding.yaml`，入口为
`scripts/ablate_soft_spatial_encoding.py`。

仅加载中央浅 / 深两条训练轨迹及共享网格，不加载验证、测试轨迹数组。
复用原固定名单，未按本轮标签、残差或训练成绩重新挑选：

| 轨迹 | 按压帧 / 当前时间 s | 保持帧 / 当前时间 s |
| --- | --- | --- |
| center_deep | 71 / 0.71，89 / 0.89 | 110 / 1.10，128 / 1.28 |
| center_shallow | 76 / 0.76，91 / 0.91 | 110 / 1.10，128 / 1.28 |

当前输入、标签、门控、速度、邻域掩码和稳定节点编号与上一轮保存内容一致。
每帧共 140 个 Gaussian 节点：105 个活动、35 个底部固定。
八帧对合计 840 个活动节点帧、257 个接触邻域节点帧；邻域半径仍为 0.02 m。

三组分别从头训练，种子均为 **7**，完整八帧对组成一个批次，进行 **2000 次更新**。
保持 Adam 学习率 0.001、余弦衰减至 1%、`betas=(0.9,0.999)`、`eps=1e-8`、
梯度裁剪阈值 1、原归一化、门控 sigma 0.02 m 和单轴输出上限 0.001 m 不变。
仍然预测 `delta = current_velocity × 0.01 + gate × learned_residual`，
底部总增量通过硬掩码设为零，绕过自由刚体更新。

输入使用真实当前状态、动作及当前 MuJoCo 接触、力；下一帧仅构造增量监督。
Gaussian 尺度和旋转不参与学习，没有自由多步运行。

公共目标保持为：

```text
canonical_loss = 0.5 × MSE_active((predicted_delta - true_delta) / 0.001)
               + 0.5 × MSE_neighborhood((predicted_delta - true_delta) / 0.001)
backward_loss = 100 × canonical_loss
```

每组包含第 0 步，按这八帧对的最低公共目标保存权重，平局取更早步骤。
选模没有使用未见样本。诊断标准保持为总体活动节点、接触邻域 RMSE
**均比恒速降低至少 50%**；这不是泛化标准。

## 三组结构与实际参数量

| 组 | 原始输入是否保留 | 输入维度 | 两个隐藏层宽度 | 实际总参数 |
| --- | --- | ---: | ---: | ---: |
| A：原 MLP | 是 | 36 | 128 / 128 | **22022** |
| B：固定空间编码 | 是，原顺序不变 | 54 | 128 / 128 | **24326** |
| C：容量对照 | 是 | 36 | 135 / 135 | **24171** |

参数量逐组实例化后统计。三组沿用原六维输出头，仅中心的三维输出参与监督，
计数包含保留的尺度输出分支。B 的固定编码是 buffer，不是可训练参数或节点编号嵌入。

B 从共享静止网格计算 `r = rest_position / 0.03`，在完整原 36 维上下文末尾追加
`sin(π f r)`、`cos(π f r)`，固定 `f = 0.5, 1, 2`。
追加维度顺序为“频率 → sin/cos → xyz”，共 18 维，所有帧共用，未搜索其他频率。
没有使用当前形变坐标替代静止坐标，也没有引入未来状态。

C 保持原两个隐藏层同宽的结构，只调整整数隐藏宽度。
原模型参数公式为 `P(h)=h²+44h+6`；B 的目标参数量为 24326。
`h=135` 得 24171，相差 155；`h=136` 得 24486，相差 160。
因此选 **135**，在这一同宽结构族中最接近 B，差约 **0.637%**。
宽度仅按参数数量计算，没有根据训练成绩搜索。

三组使用相同种子分别初始化。输入或隐藏维度不同，因此**没有宣称全部初始权重相同**。
三组输出头均零初始化，第 0 步预测都等于恒速；各组初始参数指纹另存于摘要。

## 实测总体结果

指标是三维增量向量 RMSE，单位 **μm**，不是单坐标 RMSE。

| 方法 | 活动节点 RMSE | 接触邻域 RMSE | 比恒速下降：活动 / 邻域 |
| --- | ---: | ---: | ---: |
| 恒速 | 3.47989 | 2.44970 | — |
| A | 2.92882 | 1.58833 | 15.84% / 35.16% |
| B | **2.68307** | **1.31849** | **22.90% / 46.18%** |
| C | 2.93545 | 1.60960 | 15.65% / 34.29% |

B 相对 A 的活动节点 / 邻域 RMSE 分别降低 **8.39% / 16.99%**；
B 相对 C 分别降低 **8.60% / 18.09%**。
本次不是“只优于 A、却不优于容量对照”的情形。

**诊断标准实测未通过**：A、B、C 均未实现两区域误差相对恒速各降低至少 50%。
B 的接触邻域较接近标准，但总体活动节点的降幅仍只有 22.90%。

三组最优公共损失分别为 `1.850126e-6、1.489547e-6、1.867943e-6`，
选中步数均为 **2000**。它们是本次固定预算中的最低值，不代表已找到全局最优。
三组均未触发梯度裁剪。

按压与保持分别为 4 帧对、420 个活动节点帧，接触邻域分别有 113、144 个节点帧。

| 按压 | A | 3.92977 | 2.09378 |

B 的总体收益主要来自按压：按压活动 / 邻域误差相对 A 降低约 10.30% / 22.70%。

## 解释和未验证假设

**实测结论**：在这八帧对、种子 7、当前训练预算和近参数量对照下，
固定空间编码 B 的总体拟合优于原输入 A 和加宽原输入 C，且有保持阶段的活动节点退化。
仅加宽得到的 C 没有复现 B 的总体收益。

**合理解释**：结果支持固定静止坐标编码有助于本次共享 MLP 的残差拟合。
但 C 的参数量只是近似匹配，三组的初始化张量也不相同；单次种子运行不足以证明
全部收益都由编码唯一决定，或这种收益对其他预算、初始化和对象普遍成立。

**尚未验证**：空间编码是否改善未见位置、完整训练轨迹或自由多步预测；
是否主要帮助表示特定空间频率；保持阶段退化是否与公共损失对较大按压误差的权重贡献有关。
本轮没有频谱分析、阶段权重消融或新位置评估，不能将这些可能机制写成实测发现。
