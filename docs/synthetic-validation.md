# 可控合成实验与多步运行验证

验证日期：2026-10-13（Asia/Shanghai）。起始提交：`babdb36`。
CPU 实测：Python 3.13.5、PyTorch 2.14.1、Matplotlib 3.11.2、Apple M1 / arm64。

## 运行方法

当前机器已安装所需依赖，在仓库根目录运行：

```bash
source .venv/bin/activate
python scripts/synthetic_validation.py --device cpu
```

新环境先安装项目及可选绘图依赖：

```bash
python -m pip install -e ".[dev,experiments]"
```

本机安装时沿用首次 CPU 验证的 CA 证书修复：在 pip install 命令中加入
`--cert /opt/anaconda3/ssl/cert.pem`。其他机器使用自身有效的证书配置。
原有 `requirements-cpu-macos-arm64.txt` 保留首次验证的历史版本快照，不包含新增绘图库。

脚本默认读取 `configs/toy.yaml`。物体为原 Toy 的九个 Gaussian 网格，
尺度为 0.11；机器人尺度为 0.13，速度为 `[0, 0, -0.20]`；
质量为 0.25，惯量对角值为 0.01。重力为零，网络未训练。
使用 `eval()` 和 `torch.no_grad()`，不更新网络参数。

## 各实验的目的、预期与实测

### 1. 无接触

目的：检查物体是否在没有外力时自行运动。
机器人起始 z 为 0.60，与物体分离；即使机器人按速度下移 0.4 秒，也不会碰到物体。

预期：接触数、接触力、门控和物体运动均为零。
实测：单步检查通过；`dt=0.002` 的 200 步运行中，物体位置和速度始终为零。

### 2. 穿透深度扫描

目的：通过可直接计算的球形 Gaussian 几何和接触响应，核对力与位移。
每次从同一个静止物体状态开始，只改变机器人高度，单步 `dt=0.02`。
该范围内只有中央 Gaussian 接触机器人。

按配置，预期向下合力为 `Fz = −(800 × 穿透深度 + 12 × 0.20)`，
半隐式 Euler 的预期位移为 `Δz = (Fz / 0.25) × 0.02²`。

| 输入穿透深度 | 预期 Fz | 实测 Fz（约） | 实测 Δz（约） |
| --- | --- | --- | --- |
| 0.005 | −6.4 | −6.399984 | −0.010240 |
| 0.010 | −10.4 | −10.399981 | −0.016640 |
| 0.020 | −18.4 | −18.399984 | −0.029440 |
| 0.030 | −26.4 | −26.399988 | −0.042240 |
| 0.050 | −42.4 | −42.399986 | −0.067840 |

实测与公式预期在浮点容差内一致，力与单步向下位移随穿透深度严格增大。

### 3. 移动接触位置

目的：检查门控是否随接触位置移动，以及偏心力是否产生方向正确的力矩。
机器人 z 固定为 0.19，x 分别为 −0.18、0、+0.18。

| 机器人 x | 实测门控峰值 Gaussian 索引 | 实测合力矩 τy（约） |
| --- | --- | --- |
| −0.18 | 3（左侧） | −7.631998 |
| 0 | 4（中央） | 0 |
| +0.18 | 5（右侧） | +7.631998 |

门控峰值正确迁移，偏心力矩方向正确。热图显示九个离散 Gaussian 的门控权重，
不代表连续材料表面，也不代表已学习的形变量。
所有单步实验的局部中心及 log-scale 最大绝对变化均为 0，符合零初始化预期。

### 4. 多步与时间步比较

目的：检查递归状态更新，并量化时间步对结果的影响。
每一步重新解析接触，将输出的局部状态和刚体状态传给下一步。
机器人位置按其规定速度同步更新。每组从相同初态出发，运行同样的 0.4 秒。

使用 `dt=0.0005` 的 800 步运行作为更细数值参考，参考终态为：
`z = −1.1817070246`，`vz = −3.0326099396`。
它来自同一个模型，**不是仿真真值或真实物理真值**。

| dt | 步数 | 终态 z | 终态 vz | 相对参考的 z 绝对差 | vz 绝对差 |
| --- | --- | --- | --- | --- | --- |
| 0.002 | 200 | −1.181220 | −3.024972 | 0.000487 | 0.007638 |
| 0.005 | 80 | −1.188357 | −3.030774 | 0.006650 | 0.001836 |
| 0.010 | 40 | −1.223523 | −3.101030 | 0.041816 | 0.068420 |
| 0.020 | 20 | −1.356799 | −3.391999 | 0.175092 | 0.359389 |

实测所有状态均为有限数值，动量变化与逐步接触冲量一致，局部形变始终为零。
物体与机器人分离后，接触力和门控变为零，物体以已有速度继续运动。
本例没有地面、重力或恢复力，因此它不会自动停止或返回原位。

原 Toy 的 `dt=0.02` 在多步中的位置偏差较明显，约为参考终态位移大小的 14.8%。
这组实验中，较小时间步对应更小的位置差；但速度差没有严格单调下降，
可能受离散接触切换时刻影响，需要进一步细化时间步研究。
“没有 NaN/Inf”不能单独证明稳定性，“接近数值参考”也不能证明物理正确性。

后续多步开发可以先用 `dt=0.002` 作为当前场景的工作基线，
继续保留时间步扫描。该值不是其他材料或接触场景的通用稳定性保证。
本次不修改原 Toy 配置，保留首次运行结果的可复现性。

默认目录 `outputs/synthetic_validation/`（由 `.gitignore` 忽略，可重新生成）：

| 文件 | 用途 |
| --- | --- |
| `single_steps.csv` | 单步实测值与公式预期值 |
| `rollouts.csv` | 所有时间步、数值参考及无接触运行的逐步记录 |
| `time_step_comparison.csv` | 各时间步终态及参考差值 |
| `summary.json` | 配置、环境、门控数组、23 项检查及数值比较 |
| `penetration_sweep.png` | 力与位移的公式预期 / 实测对照 |
| `contact_gates.png` | 左、中、右接触的门控热图 |
| `rollout_comparison.png` | 位置、速度、力、穿透、接触数与门控随时间变化 |
| `time_step_error.png` | 终态相对更细数值参考的差值 |

CSV 中，接触量和 `robot_z_start` 对应 `time_start`，
刚体位置 / 速度及 `robot_z_end` 对应 `time_end`，两种采样时刻不能混用。
`local_center_change_max` 和 `local_log_scale_change_max` 是该步局部增量。
JSON 保存每项检查的预期和观察值；任何行为检查失败，脚本以退出码 1 结束。
时间步差值属于测量结果，没有用“误差必定单调下降”作为通过条件。

可通过 `--output-dir` 指定其他输出位置；`--duration` 必须是所有比较时间步
和参考时间步的整数倍，`--reference-dt` 必须更小。
这些验收场景针对原 Toy 配置；改变材料或几何配置后，应同时评估是否需要调整预期。
缩短运行时长可能尚未发生分离，相应分离检查会失败。
