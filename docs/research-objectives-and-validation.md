# 原始研究目标与主线验证

更新日期：**2026-10-27**。

## 保持不变的研究目标

研究面向局部可变形物体的显式接触驱动 Gaussian 世界模型：

```text
当前物体 / 压头 Gaussian 状态与动作
    → 当前接触几何
    → 显式接触力
    → 满足边界约束的状态转移
    → 下一时刻 Gaussian 状态
```

需要同时回答两个问题：

1. **接触机制是否正确。** 模型对接触位置、法向、压入和相对运动的响应，
   是否与独立物理求解器一致，能否在受控干预下保持正确的响应方向、区域和时间变化。
2. **显式表示是否有实际价值。** 与公平的预测基线及消融相比，
   是否改善预测、接触变化下的响应或可定位误差的能力，并明确代价和失败条件。

这两个问题都保留。仅有较低 RMSE 不能证明接触机制正确；
仅把几何、力或门控写进代码，也不能证明学习模块正确使用了它们。
本项目把“理解物理接触”落实为这些可检验行为，不把它当作没有验收定义的结论。

总体研究允许近刚体运动与局部形变组合；当前软块底部固定，必须遵守固定边界，
不能把接触合力直接转换成整个软块的自由刚体运动。
目前节点对应 Gaussian 中心，尺度与旋转固定；视觉重建和渲染仍是后续模块。

## 最近实验的定位与已知边界

固定恢复片段、微扰响应和响应权重对照属于内部动力学排障，历史结果全部保留。
它们不是主线研究目标，也不以持续降低同一小片段损失作为下一阶段验收。

已经实际观察到：

- 固定第 210–230 帧的恢复窗口没有接触，接触支路未训练。
  拟合、响应和振动结果只约束内部恢复动力学，不能证明接触机制成立。
- 完整轨迹的联合状态模型接触分支得到训练，但当前 `JointStatePipeline.current_inputs`
  固定调用 `mujoco_force`，使用原生当前几何与真实力作为调试条件。
  这不能作为高斯几何 / 解析力已经完成替代的证据。
- 早期三组接触管线已经实际运行，但使用的是旧位移网络。
  高斯几何在左侧验证的受力接触帧召回率仅 **7.65%**，是已知严重局限；
  不能把漏检后更接近恒速的某项分数解释为几何更好。
- 新联合状态模型改善了一些释放 / 恢复指标，按压 / 保持仍有退化。
  固定片段的响应监督减少放大，同时伴随振幅偏低，尚未正确重现完整弹性动力学。

## 主线需要的证据

| 要回答的问题 | 主要实验 | 需要保存的证据与局限 |
| --- | --- | --- |
| 接触是否被正确定位 | 当前预测状态下的原生 / 高斯几何比较 | 接触召回、误报、首次接触与脱离时刻、接触位置 / 法向误差；有无接触分别报告 |
| 解析力近似是否可用 | 同一几何的原生力 / 解析力比较 | 世界坐标合力、方向与时间变化误差；只在训练轨迹标定，不直接拿杨氏模量作弹簧刚度 |
| 学习模块是否正确使用接触 | 同一软体当前状态下改变压头条件，用独立求解器生成参照 | 预测响应差与真实响应差，响应区域、符号及短时状态变化；不回填未来软体状态 |
| 显式接触带来什么收益 | 完整模型与恒速、移除接触信息及同容量无显式接触模型比较 | 分阶段 / 分区域的状态误差、接触响应；训练预算、输入权限及选模一致 |
| 收益是否离开训练样本仍存在 | 完整轨迹划分及未见接触条件 | 训练与评价分离，包含失败片段，不只展示选中的恢复窗口 |

不要求模型在每个场景、每个指标都领先，但研究结论必须说明：
收益出现在哪里、机制证据是什么、哪一环节失效，以及哪些解释仍未验证。
诊断发现失败本身可以作为阶段产出；对最终方法的优势主张仍需相应证据。

## 干预与消融要分清

**物理干预：**固定相同软体当前位置与瞬时速度，改变压头的位置、运动或指令，
由独立 MuJoCo 积分产生不同下一状态；模型也从这些一致的当前条件重新计算接触。
对比的是模型预测的响应差与求解器产生的响应差，减少不同初始状态的混淆。
预期响应以独立求解结果为准，不预设所有指标都应单调。

**网络输入消融：**冻结模型后删除或替换接触信息，检查输出是否改变。
这可以测量依赖关系，但可能产生训练分布外或物理上不一致的输入。
仅有“力删掉后预测变了”不能证明模型学到了正确物理，需和物理干预证据结合。
若要评价显式输入结构的训练收益，还需要从头训练公平的消融模型，不能仅做输入置零。

## 下一阶段唯一主线：接触机制审计

使用已有小规模数据，冻结**完整轨迹训练过接触分支**的联合状态模型，
而非最近几份只拟合无接触恢复窗口的检查点。

1. 接回原有三组条件：原生几何 + 原生力、原生几何 + 解析力、高斯几何 + 解析力。
   三组共享当前状态、网络、样本和评价掩码，后两组不调用真实力。
   先把几何误差、力误差和状态转移误差分开定位。
2. 在预先固定的代表性当前状态上，做小规模接触 / 脱离和接触位置干预，
   用独立求解器给出参照，检查模型是否产生对应的空间和动力学响应。
3. 按接近、按压、保持、释放、恢复报告单步与 5 / 10 / 20 步结果，
   同时保留恒速和输入消融。连续递推只给定外部压头输入，软体状态自回归。

中央训练轨迹供既有训练 / 标定，左侧用于当前验证与机制审计；
右侧在协议和模型冻结前继续保留，不据其结果调整规则。
三组替换条件是在冻结网络下的诊断：若分布与原训练条件不同，要记录这种差异，
不能将全部状态退化归因于几何或力近似。
同容量无显式接触模型属于后续公平训练对照，当前尚未完成。

本阶段验收是得到可运行、可复核的机制证据和误差归因，
不把单一 RMSE 胜出或某条曲线更平滑作为通过标准。
只有当具体故障阻碍这项主线验证时，再做有明确停止条件的局部诊断。

冻结完整轨迹模型后，三组接触条件、输入消融、单步 / 多步与 18 条独立干预均已运行。
