# 自主恢复分支的邻域信息消融

日期：2026-10-26。已在当前 Apple M1 / CPU 实际完成 A、B、C 各 2000 次更新、
全部单步评价和 5 / 10 / 20 步预测。结果目录：`outputs/neighbor_recovery_ablation/run_001/`。

后续已完成[固定恢复片段的一步 / 五步监督诊断](recovery-multistep-diagnostic.md)：
B 可拟合短时振动，但更长递推仍出现速度误差放大，本页保留原消融结果。

**本次六维邻域均值特征没有带来稳定的动力学优势，也未恢复真实振动。**
B 在部分单步、20 步和恢复位置指标上改善，但另一些指标退化：
5 / 10 步位置较 A、C 更差，20 步速度略差于 C，按压 / 保持单步退化，恢复振幅仍严重偏小。
因此不将 B 作为已验证优于 A、C 的新主模型，不宣称空间耦合问题或跨位置泛化已解决。

## 目的与固定协议

本轮检验：上一轮内部恢复支路只读取单个节点的当前状态，是否因此缺少恢复振动所需的邻居信息。

1. 复现上一轮自主模型 A，先确认实验起点一致。
2. 仅给内部支路增加固定网格邻域信息，得到 B。
3. 将原输入内部网络适当加宽为 C，排除参数量增加的影响。
4. 沿用同一损失、样本和选模规则，保留所有阶段及无接触帧。
5. 同时检查位置、瞬时速度、固定探针振幅和有符号曲线，防止把压低速度误当作恢复成功。

入口：`scripts/ablate_neighbor_recovery.py`；独立配置：`configs/ablate_neighbor_recovery.yaml`；
新增模型：`src/contact_gwm/neighbor_dynamics.py`；结果分析：`scripts/summarize_neighbor_ablation.py`。
已有训练辅助函数只增加可选的架构元数据参数，未改变优化计算；原模型与全部历史输出保留。

固定中央两条训练轨迹，共 **600 帧对**；左侧两条验证轨迹 **600 帧对**；
无接触对照 300 帧对只评价。右侧测试数组未加载。
全部阶段和交界帧保留；网络输入使用当前状态、当前 MuJoCo 原生几何和真实力，
几何候选仍为所有 gap≤0 接触，未按真实力阈值筛选输入。

共同使用种子 **7**、CPU 单线程、dt=0.01 s、Adam、学习率 0.001、
余弦衰减至 1%、batch=16、2000 更新、梯度裁剪 1，位置 / 速度输出上限和归一化不变。
训练 minibatch 顺序相同。每 50 步评价完整验证集，第 0 步参加选模；
仅按原位置—速度联合验证损失保存最低权重，rollout 不参与选模或调参。

公共目标保持：两区域坐标 MSE 等权，位置误差除以 0.001 m、速度误差除以 0.1 m/s，
位置与速度两项再等权，反向损失乘 100。下一帧只构造监督，不进入输入。
独立速度增量更新、硬固定底部、给定压头轨迹的软体自回归定义均沿用上一轮。

## 邻域信息和容量对照

静态 `mesh.npz` 含 140 个稳定节点、679 条无向边、432 个四面体。
这些边恰为四面体边的集合，节点度 4–14。
35 个底部固定节点保留为邻居，位移和速度强制为零；其中固定—活动边 117 条。

令 `u_i=x_i-rest_i`，在原内部输入末尾追加：

```text
neighbor_u_i = mean_{j in rest_mesh_neighbors(i)}(u_j-u_i) / 0.01
neighbor_v_i = mean_{j in rest_mesh_neighbors(i)}(v_j-v_i) / 0.05
```

共六个无量纲通道。边双向使用、去重、去自环，均匀平均，不学习权重，不搜索聚合规则。
直接使用原当前特征中的归一化形变 / 速度，避免改变 A 的数值路径。
每次 rollout 都从**当前预测状态**重新计算邻域；不回放真实邻域状态。
静止平衡参考的六个新增通道为零，只有内部网络改变，接触支路不读取这些新增特征。

| 组 | 内部输入维度 | 内部两层宽度 | 接触输入 / 两层宽度 | 内部参数 | 总参数 |
| --- | ---: | ---: | --- | ---: | ---: |
| A：原自主模型 | 28 | 128 / 128 | 54 / 128 / 128 | 20998 | 45324 |
| B：邻域均值 | 34 | 128 / 128 | 同上 | 21766 | 46092 |
| C：容量对照 | 28 | 131 / 131 | 同上 | 21883 | 46209 |

接触支路均为 24326 参数。C 比 B 多 117 参数，差约 **0.254%**；
内部宽 130 时总参数 45912，与 B 差 180，因此固定选 131，没有按成绩搜索宽度。
原内部参数公式为 `h²+36h+6`，加上固定接触分支计算总参数。
邻域矩阵是固定 buffer，不算可训练参数。

三组从头初始化。三组接触支路的初始权重逐项相同；
B 复制 A 未训练的公共内部权重，六个新增输入列初始为零，随后正常学习。
C 的内部维度改变，因此**没有宣称三组全部初始权重相同**；各组完整参数指纹另存。

**复现检查实际通过**：A 的所选检查点与上一轮 `autonomous_joint` 逐位一致，仍选第 100 步；
原输入缓存、全部标签、ROI 和样本名单也逐位相同。

## 实测单步结果

所有方法使用相同评价掩码。活动区域为 105 个非固定节点；
接触邻域沿用半径 0.02 m 的参考 ROI，脱离后保留最后 ROI，首次接触前用静止顶面 ROI。
掩码只用于损失 / 评分，不作为输入。指标为 XYZ 向量 RMSE，按节点 SSE 汇总后开根号。

左侧全部 600 帧对，增量单位 μm，下一时刻瞬时速度误差单位 mm/s：

| 方法 | 活动增量 | 活动速度 | 接触邻域增量 | 接触邻域速度 |
| --- | ---: | ---: | ---: | ---: |
| 恒速 | 15.537 | 2.755 | 20.048 | 3.422 |
| A | 14.236 | 2.401 | 18.406 | 3.067 |
| B | 14.143 | 2.302 | 18.876 | 3.008 |
| C | 14.219 | 2.394 | 18.418 | 3.068 |

B 活动增量 / 速度相对 A 改善 **0.65% / 4.12%**，相对 C 改善 **0.53% / 3.85%**；
但接触邻域增量比 A / C **退化 2.55% / 2.49%**。
所以不能概括为 B 的单步位置、速度在两区域都更好。

按阶段拆分活动区域，各格为 **增量 μm / 速度 mm/s**：

| 阶段 | 恒速 | A | B | C |
| --- | ---: | ---: | ---: | ---: |
| 按压 | 4.651 / 0.864 | 6.252 / 1.174 | 7.827 / 1.319 | 6.385 / 1.197 |
| 保持 | 1.657 / 0.315 | 5.256 / 1.036 | 6.349 / 1.251 | 5.341 / 1.032 |
| 释放 | 32.206 / 5.633 | 28.796 / 4.757 | 28.008 / 4.448 | 28.722 / 4.738 |
| 恢复观察 | 9.371 / 1.802 | 8.714 / 1.569 | 8.747 / 1.536 | 8.698 / 1.563 |

按压、保持中 B 的活动增量比 A 分别退化约 **25.2% / 20.8%**。
恢复观察单步位置也没有超过 A、C，速度略有改善。
接近阶段、有 / 无接触、全部逐轨迹及邻域结果见 CSV，没有只保留改善项。

## 结论和唯一后续优先项

**实测结论**：B 未稳定优于 A，也未稳定优于参数量接近的 C。
它改善少量指标，且在部分恢复位置指标上有明显收益，但未解决恢复速度、振幅和保持平衡。
当前证据不支持把六维邻域均值当作解决方案。

**解释边界**：均值特征会压缩邻居的方向信息，并不等价于应变张量、真实弹性内力或完整图模型。
本轮未否定空间耦合的价值，也未确定问题唯一来自输入、优化、单步目标或自回归误差。
单种子且 C 内部初始张量不同，微小百分比差异不应被解释为普遍优势。

**下一轮只优先做固定恢复片段的短时多步可拟合性诊断**：
保持 B 结构，在同一固定中央无接触窗口比较一步与 5 步联合位置 / 速度监督，
检查连训练窗口的振幅和换号能否拟合，再区分表达不足和单步目标 / 自回归累积的问题。
这一诊断尚未运行，其收益是假设；暂不增加数据、渲染器或更复杂的接触条件比较。
