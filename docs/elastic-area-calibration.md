# 中央轨迹弹性面积刚度标定

日期：**2026-10-29**。已在当前 Mac / CPU 实际完成。
主结果：`outputs/elastic_area_calibration/run_002/`。

**标定得到 `k_A = 63,796,521.10025896 N/m³`。**
只用中央浅 / 深轨迹的按压、保持阶段，先保存参数，再读取左侧力标签验证。
左侧全帧法向合力 RMSE 为 **0.083489 N**，比零力低 **20.57%**，
但比同标定协议的点式参照高 **14.11%**。
面积模型在按压阶段较好，保持和释放较差，不能把积分修复称为力模型已验证。

## 标定什么、保持什么

复用上一轮[裁剪自适应积分](adaptive-contact-integration.md)的冻结当前状态几何基底：

```text
D = sphere_radius + skin
delta(q) = max(D - ||q-c||, 0)                         # m
n(q) = (q-c)/||q-c||                                 # 球 → 软块，世界坐标
I = ∫ delta(q) n(q) dA                               # m³
J = ∫ (q-origin) × delta(q) n(q) dA                  # m⁴
F = k_A * I                                         # N
tau = k_A * J                                       # N·m
```

只拟合一个非负常数，零截距，阻尼和摩擦均为零；不改变表面、skin、积分容差或门控。
这是局部压力律 `p = k_A * delta` 的**有效接触参数**，不是材料杨氏模量，
也不能和旧点弹簧的 N/m 系数直接比较大小。
例如本模型中压入 0.1 mm 对应约 6.38 kPa 压力，不代表独立测得材料参数。

已知拓扑的连续材料面由当前 Gaussian / 节点中心构造，仍依赖初始网格拓扑。
面积力预测接口只接收几何积分，不接收 MuJoCo 力、下一帧状态或下一帧力。
无接触时为零是模型规定；本轮不因此声称解决了无接触弹性恢复。

底部 35 个固定节点在几何积分前恢复静止位置 / 零速度。
力矩参考点与上一轮一致，是当前活动节点的质量质心，固定节点质量权重为零。
由于法向沿球半径，`J = (c-origin) × I`；15 个重放状态中恒等式误差最大
`2.02e-28 m⁴`。这里仅计算外接触力与力矩，不执行自由刚体或局部状态更新，
不修改速度，也没有训练任何网络权重。

## 样本、真值和求解方法

- 训练：`center_shallow`、`center_deep`，阶段 1 / 2，共 **200 帧**，其中 **151 帧**基底非零。
  包含按压初期的 49 个零接触帧，不按结果删样本；名单在 `fit_samples.csv`。
- 验证：`left_shallow`、`left_deep`，每条第 0–299 帧，共 **600 帧**。
- 无接触对照：`no_contact`，300 帧。中央全阶段也报告 600 帧。
  第 300 帧端点未纳入，与原积分归档的 300 个当前状态保持一致。
- 保留接近、按压、保持、释放、恢复所有阶段；右侧轨迹数组未加载。
  左侧已有历史诊断，不称为未触碰的盲测。

标签来自原先保存的独立 MuJoCo 求解器。取当前有效接触 `gap <= 0`，
根据 flex 所在侧调整接触坐标系的法向符号，
将保存的世界力投影到单位法向，求和得到软块所受法向合力。
符号与法向长度检查通过；保存的世界总力重新求和与归档净力最大差 **0 N**。
总力 / 总力矩另行报告，含切向分量；本模型没有摩擦，不能将其解释成已拟合完整力。
标签力矩用归档接触点到同一当前质心的力臂计算；归档的接触内禀力矩实际为零。

目标是各帧等权的世界向量平方误差，不是每个接触候选等权：

```text
min_{k >= 0} Σ_t || k I_t - F_normal_native,t ||²
k = max(0, Σ_t I_t·F_normal_native,t / Σ_t ||I_t||²)
```

基底按 `1e-9 m³` 缩放只改善数值尺度，不改变目标或单位。
这是单列最小二乘的直接解，没有学习率、迭代次数或验证集选参。
本次非负约束未激活，训练目标平方误差和为 **4.218071 N²**，
200 帧向量 RMSE **0.145225 N**，接触 151 帧 RMSE **0.167135 N**。
已经得到这个单参数目标的最优解，继续调同一常数不能消除训练残差。

参照模型均只含弹性法向力：

- 零力：`F=0`、`tau=0`。
- 历史点式：旧系数 **691.386733 N/m**，之前按接触拟合，保留作为历史参照。
- 同协议点式：`F = k_point * Σ_i delta_i n_i`，仅用相同中央 200 帧、
  相同法向合力目标，得到 **519.596895 N/m**，训练 RMSE **0.119497 N**。
  同样零截距、非负、无阻尼摩擦，未用力矩选参。

点式参照读取当前归档的原生接触几何；面积模型用冻结的拓扑辅助连续面。
“同协议”指划分、帧、标签与拟合目标一致，不代表两种几何表示相同。
两者参数及 `material.json` 均在加载左侧力标签前保存，验证后校验面积参数未变。
`run_001` 是添加同协议点式参照前的完整运行，保留；`run_002` 补齐该对照，
两次面积参数文件与全部面积力 / 力矩预测**逐位相同**，没有据左侧调参。

## 实测：左侧全阶段

RMSE 定义为 `sqrt(mean_t(||预测向量-真值向量||²))`，不是按 XYZ 分量再除 3。
接触帧以真实法向合力模长 `>1e-8 N` 定义，四组使用同一掩码。

| 方法 | 全 600 帧法向力 RMSE / N | 接触 183 帧法向力 RMSE / N | 全帧法向力矩 RMSE / N·mm |
| --- | ---: | ---: | ---: |
| 零力 | 0.105114 | 0.190331 | 1.884842 |
| 历史点式 | 0.078612 | 0.142344 | 1.477239 |
| 同协议点式 | **0.073169** | **0.132487** | **1.343791** |
| 面积弹性 | 0.083489 | 0.151175 | 1.514907 |

面积模型的全帧**总力** RMSE 为 **0.083518 N**、**总力矩** RMSE 为 **1.515183 N·mm**；
同协议点式分别为 **0.073207 N / 1.343741 N·mm**。
全阶段法向力相对 L2 误差：面积 **79.43%**，同协议点式 **69.61%**。
所以相对零力的改善不代表绝对误差已经足够小。

三种非零力模型对这 183 个接触帧均为误报 **0**、漏报 **0**；
零力漏报 183 帧。`no_contact` 300 帧四组力和力矩均为零。
这些检测结论只针对本批保存的当前状态及上述阈值。

## 曲线、解释与未验证假设

![法向力曲线](../outputs/elastic_area_calibration/run_002/normal_force_curves.png)

![左侧力矩曲线](../outputs/elastic_area_calibration/run_002/validation_torque_curves.png)

**实测：**面积预测向下，保持和释放期间明显低估合力。
左侧保持阶段真实平均 `Fz=-0.210371 N`，面积模型仅 **-0.029567 N**；
释放阶段为 **-0.043417 / -0.001977 N**。四条轨迹都有保持平台低估现象。
积分精度已在上一轮用独立数值参照检查，当前单参数最小二乘也经独立 SVD 复核；
因此当前证据不支持继续增密积分点或反复优化同一个标量来解决这类曲线差异。

**解释：**本轮直接暴露的是冻结几何下，单一 `k_A * ∫delta*n*dA` 压力律与原生法向标签不充分一致。
同协议点式总体更好，面积积分消除了逐点求和的密度问题，但没有自动带来更准确的接触力。
不能据此判定所有面积模型无效，也不能把全部误差归到局部网络或速度更新：本轮没有执行它们。

**尚未验证的假设：**MuJoCo 约束 / 接触柔度与软体内部弹性支撑的耦合，
可能使归档的法向支撑力不能由当前几何穿透的单一常数决定；动态耗散也可能参与标签。
“法向标签”不等于分离出的“纯弹性标签”，本参数只是这一场景 / 协议下的有效拟合。
保持平台的差异是否主要来自求解器压力律、接触柔度或内部应力，需要独立证据。
未做非线性压力律、阻尼标定、法向偏置、阶段专用系数或验证集搜索。

下一项优先检查**中央保持段的穿透—原生支撑力关系与求解器接触柔度**，
先解释平台低估，再决定是否修改压力律；不直接把这个尚不准确的力接入旧网络后宣称动力学改善。
上一轮 **17 帧阻尼局部未收敛标记仍保留**，其中面积 / 弹性局部失败为零，
本次 `c_A=0`，没有丢弃这些帧，也没有将阻尼检查改成通过。
