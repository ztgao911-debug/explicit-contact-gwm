# 恒速残差诊断与 8 帧对拟合

日期：2026-10-15，当前 Mac / CPU 实测。本轮完成了残差统计、两次小样本训练、
模型保存及重新加载、曲线和空间图检查。**小样本拟合仍不足；仅缩小输出上限没有改善。**
这是对训练流程的诊断，不能作为泛化结果。

## 这一步在检查什么

1. **看真实残差**：计算 `r[t] = x[t+1] - x[t] - v[t] × 0.01`，
   确认恒速预测还留下多大的误差、分布在哪里。这里的下一帧仅用于监督标签。
2. **固定少量样本反复拟合**：先检查网络能否记住很小的训练集，
   避免将优化或表示上的问题误当成数据量不足。
3. **只改变输出上限**：原设置拟合不足后，用中央样本的残差幅度确定一次对照，
   检查输出尺度这一因素。没有同时修改损失、归一化或网络规模。

保留当前真值状态、当前 MuJoCo 接触与力作为输入。底部固定，绕过自由刚体更新，
Gaussian 尺度和旋转不变。仍然是一步预测，没有自由多步运行。

## 数据和诊断协议

- 读取 `pilot_001` 中中央浅 / 深两条训练轨迹、左侧浅 / 深两条验证轨迹，以及共享网格。
- 沿用当前接触且相邻两帧均为按压 / 保持的筛选规则，中央、左侧各 **149 帧对**。
- 活动节点 **105**，固定节点 **35**；接触邻域仍为距当前接触点 0.02 m 内的活动节点。
- 本轮不加载右侧测试轨迹数组，不重新评估原测试集。
- 在每条中央轨迹的按压、保持阶段，分别选时间顺序的 25% 和 75% 分位帧，
  共 **8 帧对**。选择只依赖轨迹、当前阶段和时间顺序，不依赖残差大小或未来标签。

固定样本如下；时间保留两位小数，完整精度见运行目录的 `fixed_samples.json`。

| 轨迹 | 按压帧：编号 / 当前时间 s | 保持帧：编号 / 当前时间 s |
| --- | --- | --- |
| center_deep | 71 / 0.71，89 / 0.89 | 110 / 1.10，128 / 1.28 |
| center_shallow | 76 / 0.76，91 / 0.91 | 110 / 1.10，128 / 1.28 |

每种设置均从相同种子 7 和零输出层开始，原两层 128 维 SiLU 网络、22022 个参数。
全量 8 对组成一个批次，每轮一次更新，训练 **2000 epoch**；
Adam 学习率 0.001，余弦衰减至 1%，裁剪阈值 1。
原归一化、`loss_unit_m=0.001`、活动节点 / 邻域各 0.5 的损失均保持不变。

权重按**这 8 对本身**的最低加权 MSE 选择，包含 epoch 0，平局取更早一轮。
这是有意进行的训练集记忆检查。训练函数不接收验证集，选定并保存权重后才计算左侧预测。
没有用左侧误差挑选这次诊断权重，也没有据左侧结果继续调整参数。

## 实测残差

下表统计所有活动节点，单位为 **微米（μm）**，数值为三维向量 RMS，
即 `sqrt(mean(dx² + dy² + dz²))`，不是单坐标 RMS。1 μm = 0.001 mm。

| 数据 / 阶段 | 真实增量 RMS | 恒速残差 RMS | 残差占增量 RMS |
| --- | ---: | ---: | ---: |
| 中央 / 按压 | 30.724 | 5.257 | 17.1% |
| 中央 / 保持 | 2.736 | 1.417 | 51.8% |
| 左侧 / 按压 | 32.503 | 5.969 | 18.4% |
| 左侧 / 保持 | 3.127 | 1.671 | 53.4% |

中央按压残差向量的中位数 / 99 分位 / 最大值分别为 2.685 / 17.369 / 130.521 μm；
保持阶段分别为 0.777 / 4.916 / 8.821 μm。少数大残差不能用平均值概括。
时间曲线中，接触初期误差较大，保持阶段整体较小；这些现象本身不能证明求解器有噪声。
空间图使用固定初始坐标标记节点，颜色表示各节点跨所选阶段帧的残差 RMS，
并非形变幅度或接触力。残差也分布在接触邻域以外。

完整统计还包含逐轨迹、逐阶段、接触邻域的分位数、门控范围及输出限幅误差下界，
见 `residual_statistics.csv`。

## 8 帧对拟合：预期与实测

本轮运行前将“同一 8 对上，活动节点和接触邻域 RMSE 均比恒速降低至少 50%”
设为诊断标准。这个标准仅用于判断是否已明显拟合，不是统计显著性标准。

| 设置 | 活动节点 RMSE μm | 接触邻域 RMSE μm | 相对恒速降幅：活动 / 邻域 |
| --- | ---: | ---: | ---: |
| 恒速基线 | 3.4799 | 2.4497 | — |
| 原输出上限 1000 μm | 3.1657 | 1.8544 | 9.03% / 24.30% |
| 输出上限 100 μm | 3.1899 | 1.8807 | 8.33% / 23.23% |

两次都未达到诊断标准，缩小输出上限略差。两次最低损失都在 epoch 2000，
训练及逐轮评估耗时分别为 **5.21 s、5.31 s**；包含加载、校验、绘图和保存的总耗时
分别约 **17.68 s、17.86 s**。没有根据未达标准而延长训练或继续搜索其他设置。

原设置按压 / 保持活动节点 RMSE 为 4.2696 / 1.3465 μm，
对应恒速为 4.7091 / 1.4295 μm。
原设置保持阶段的接触邻域 RMSE 为 1.1424 μm，反而高于恒速的 1.0645 μm。
因此总体损失降低不代表每个阶段都得到改善。

### 为什么选 100 μm 做一次对照

这 8 对的 `abs(true_residual_axis) / current_gate` 最大约为 **74.75 μm**，
选择 100 μm 可覆盖全部固定样本的单轴目标。固定样本上的限幅理论误差下界为零，
因此本次小样本拟合不足不能仅归因于输出上限太小。

这个上限不能直接当作整个数据集的最佳设置：中央所有 149 对需要的最大未门控单轴
残差约 130.67 μm，左侧约 795.87 μm，后者还受到远处较小门控的影响。
100 μm 上限在中央 / 左侧全部活动节点上的乐观限幅误差下界分别约 0.247 / 0.850 μm；
这只计算逐轴范围约束，忽略共享 MLP 的表达限制，也没有证明模型可以达到该下界。

## 冻结小样本权重后的完整轨迹检查

这些网络只拟合过 8 对。以下完整轨迹误差用于说明这种拟合能否直接迁移，
没有据此选模，也不是重新完成了原先的完整轨迹训练协议。单位均为 μm。

| 方法 | 中央全部 149 对：活动 / 邻域 | 左侧全部 149 对：活动 / 邻域 |
| --- | ---: | ---: |
| 恒速基线 | 3.7711 / 3.5724 | 4.2942 / 4.7890 |
| 原上限，拟合 8 对 | 3.8303 / 3.5998 | 7.2396 / 10.3214 |
| 缩小上限，拟合 8 对 | 3.8084 / 3.5648 | 5.1937 / 6.7839 |

两种小样本网络的左侧误差均高于恒速基线，没有得到新的迁移改善证据。
输出尺度单独调整没有解决问题，后续仍须区分优化设置、输入表示、网络表达等可能原因。
本轮不能据此声称已经找到失败根因，也不能断定独立求解器标签有问题。

## 复现

使用已建立的虚拟环境，不需新增依赖。已有目录拒绝覆盖，重跑应指定新目录：

```bash
source .venv/bin/activate
python scripts/diagnose_soft_residual.py \
  --output-dir outputs/soft_residual_diagnostics/repeat_original
python scripts/diagnose_soft_residual.py \
  --config configs/diagnose_soft_residual_scaled.yaml \
  --output-dir outputs/soft_residual_diagnostics/repeat_scaled \
  --compare-to outputs/soft_residual_diagnostics/repeat_original
python -m pytest
```

下一步建议先做更小的**单帧 / 单节点强拟合检查及梯度诊断**，确认现有输入和网络能否
拟合确定的残差目标，再选择一个因素继续修改。当前证据不足以支持扩大采集、
把缩小上限作为正式改进，或直接进入自由多步训练。方法确定后的最终评估应使用新采集的完整轨迹，
避免反复查看已经使用过的右侧测试集。
