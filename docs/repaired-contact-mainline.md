结果目录：`outputs/repaired_contact_mainline/run_001/`。

**主线已重新接通：修正表面 G 的接触检测与 F 的预测差距基本消除，
但局部模型仍没有通过独立接触干预检验。**

## 本轮做了什么

用完整轨迹训练过接触支路的联合状态网络，接入修正后的拓扑辅助连续表面。
先检查几何、力与局部输入接口，再运行全部单步、短时递推与独立求解器干预。
没有训练网络、重新标定参数、挑选片段或扩大正式数据集。

| 标记 / 方法名 | 当前接触几何 | 当前力 | 用途 |
| --- | --- | --- | --- |
| M / `mujoco_force` | 原生几何 | 当前状态的原生求解力 | 调试参照，不能保证网络预测最佳 |
| F / `analytic_force` | 与 M 相同 | 点式弹性法向力 | 与 M 比较力近似影响 |
| G / `gaussian_geometry` | 修正后的拓扑辅助连续面 | **与 F 同公式、同参数** | 与 F 比较几何替代影响 |
| A / `area_geometry` | 相同材料面，面片合力代表点 | 面积弹性力 | 单独的压力律 + 输入适配诊断 |
| S / `sparse_geometry` | 历史稀疏 Gaussian 节点球 | 与 F、G 相同 | 在同参数下评估表面修正影响 |
| I / `internal_only` | 删除接触输入 | 删除接触输入 | 保留内部动力学的冻结输入消融 |
| CV / `constant_velocity` | 无 | 无 | 恒速、固定边界基线 |

三条主路线是 **M / F / G**。A 的接触代表点和力公式均改变，不能把 A–G 的差异全部归因于力律。
I 没有从头公平重训，也不是同容量无显式接触模型。
所有网络分支共享同一份 **45324 参数**权重：
`outputs/joint_state_recovery/run_001/autonomous_joint/checkpoint.pt`，原第 100 次更新选中。
本轮参数更新次数 **0**，保存的网络摘要未变。

## 冻结协议与输入权限

- 种子 7、CPU 单线程、`dt=0.01 s`、原归一化、宽度、空间编码、门控和输出上限全部保留。
- 复用[中央标定](elastic-area-calibration.md)：点式 `k=519.5968946439034 N/m`，
  面积 `k_A=63796521.10025896 N/m³`。两者来自相同中央 200 帧 / 法向合力目标，
  所有解析分支的阻尼、摩擦均为零。本轮不重新拟合，也不根据左侧结果改变参数。
- 这与历史审计的 `k=691.386733 N/m`、有切向力的设置不同。
  因此本轮保留同新参数的 S，**不拿新 G 与旧审计 G 的分数直接归因于几何**。
- 中央浅 / 深、左侧浅 / 深、无接触对照共五条，每条 300 对，**1500 对 / 方法**。
  所有接近、按压、保持、释放、恢复帧参加；右侧数组未加载。
  左侧此前参与选模和诊断，本次是验证 / 机制审计，不是未触碰的测试。
- 每方法沿用 30 个窗口，起点 **70 / 110 / 140 / 150 / 170 / 210**，递推 20 步，
  提取 5 / 10 / 20 步；左侧共 12 个窗口。按初始帧阶段分组，跨阶段窗口仍保留。
- **给定压头轨迹的软体预测**：只在起点读软体真实位置、瞬时速度，
  后续接触由各自预测状态重新计算；外部压头位置、速度和指令是已知输入。
  不回填软体真实状态、接触或力。M 的原生力也从当前预测状态重新求解。
- 140 个 Gaussian / 动力学节点，35 个底部固定、105 个活动；尺度与旋转不训练。
  固定中心设回 rest、速度及增量为零，不将合力用于整个软块的自由平移 / 旋转。
- 位置和瞬时速度使用原网络的独立监督输出头，保持原有限时间离散状态映射。
  没有将位移除以 dt 当成端点速度；这种映射尚不保证连续动力学或能量一致。

评价使用三维向量 RMSE，按节点误差平方和汇总后开根号。
活动节点 / 接触邻域（ROI）掩码对全部方法相同；半径 0.02 m。
无接触时延续参考邻域，首次接触前用静止顶面参考点；rollout 固定起点 ROI。
真值仅用于评分，不进入前向。

## 接入面积力时处理的具体问题

原冻结编码器按距离核对**候选力做归一化平均**。
若把每个积分节点当成独立接触点并输入微元力，增加积分阶数就会稀释输入。
本轮让积分器额外输出**原始面片**的面积和弹性向量，不改变原总积分或误差控制。
每个原面片汇总为一个合力后，才交给原编码器；没有增加动力学节点。

面片合力作用线也需与积分一致。对于平面三角片，令：

```text
I_face = ∫ delta(q) (q-c)/r dA
h = (vertex-c)·N_plane
W = I_face·N_plane / h = ∫ delta(q)/r dA
q_eff = c + I_face/W
```

`q_eff` 是面内的正权材料代表点，位于径向合力作用线上。
沿法向移到碰撞中点不会改变力矩；在同一当前质心处逐面求和，
严格保留总积分的力和力矩（运行中每次用 `rtol=1e-12, atol=1e-15` 检查）。
其速度由当前材料节点的固定重心权插值，不使用移动最近点速度。
M / F / G 的速度口径也统一为材料面瞬时速度。

**适配局限：**这样避免将积分采样密度误当候选数量，但原编码器仍做面片间归一化平均，
不保证对原始网格重新剖分不变，也未保证符合网络原训练的输入分布。
A 是冻结网络下的接口诊断，不能代替面积输入的公平重训。
`q_eff` 要求球心不在活动面片平面上；所有本轮状态均满足。
G 仍依赖已知初始网格拓扑，不代表纯 Gaussian 球并集接触问题已经解决。

## 归因与下一轮唯一优先项

**实测支持的归因：**

1. 原稀疏表面的漏检是实际瓶颈，修复后接触和状态预测更接近原生几何解析分支。
   当前这批轨迹上的 F–G 几何差距已很小，继续增密不是现有失败的充分解决方案。
2. 解析力仍有显著误差，面积弹性律保持 / 释放低估未消失；力精度与状态分数没有单调对应。
3. **局部状态转移对接触变化的响应是独立、当前更应优先解决的问题。**
   M 的几何 / 力可复现参考，仍有干预方向和幅度错误，因此不能把失败全部归因于解析力。
   位置—速度头的有限性和固定边界检查通过，不等于学得的动力学正确。

**尚未验证的解释：**普通轨迹监督可能不足以区分接触、动作与当前变形之间的相关性，
模型也可能依赖内部惯性特征或压头条件的训练相关性；A 还存在输入分布变化。
本轮没有通过权重检查或训练干预验证这些因果解释，不将其写成已证实原因。

**下一轮只优先修复局部模型在真实当前接触条件下的响应映射**：
保持几何、力参数和评价协议冻结，使用中央训练状态的独立成对干预检查 / 监督方向与幅度，
左侧继续只验证。先确认真实条件下的局部响应可学、可复核，再评价解析替代的收益。
本轮没有执行该重训，也没有把“必须赢过 CV”设为机制验收条件。
