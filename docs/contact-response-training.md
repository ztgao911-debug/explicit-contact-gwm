## 发现的具体限制：原输出上限覆盖不了部分标签

原模型每个支路、每坐标的位置残差上限 1 mm、瞬时速度增量上限 0.1 m/s。
两支路的必要上界为：

```text
|delta_x - current_v*dt| <= position_cap * (1 + contact_gate)
|delta_v| <= velocity_cap * (1 + contact_gate)
```

对初始 x / v 相同的成对响应，恒速项与内部支路相消，必要上界变为：

```text
|response_x| <= position_cap * (gate_base + gate_variant)
|response_v| <= velocity_cap * (gate_base + gate_variant)
```

中央数据要求的最大上限：绝对位置残差 **9.158 mm**、位置响应 **9.597 mm**，
绝对速度增量 **0.624152 m/s**、速度响应 **0.699383 m/s**。
原上限下，位置绝对 / 响应越界分量 **1725 / 234**，速度 **7028 / 1110**；
分母分别为 **680400 / 28350 个活动节点坐标分量**，不等于这么多独立样本。

这是增加输出上限对照的具体理由。规则预先固定为：
只读取**中央训练缓存**的必要上限，留 25% 余量，再向上取原上限的 2 次幂倍数。
得到每支路 **16 mm / 1.6 m/s**，原上限组保留，不使用左侧选取上限。
扩大后这些中央越界计数均为 **0**，零门控但响应标签非零的分量计数也为 **0**。
这是可表达范围的必要检查，不能保证 MLP 拟合或自由递推稳定。
改变上限也改变输出梯度尺度，收益不能全部解释成纯容量增加。

## 四组固定对照与公平选模

| 简称 | 实际目录 | 上限 | 初始成对响应损失 | 选中更新步 |
| --- | --- | --- | --- | ---: |
| O0 | original_absolute | 原上限 | 无 | 1700 |
| O1 | original_response | 原上限 | 有 | 300 |
| E0 | expanded_absolute | 中央推导上限 | 无 | 1950 |
| E1 | expanded_response | 中央推导上限 | 有 | 600 |

四组**从头训练**，种子 7、45324 参数、初始参数逐项相同，输出头为零，
所以原 / 扩大上限在第 0 步均为相同恒速预测。
保留旧完整轨迹模型为冻结参照，它与四个新模型的训练数据和初始化不同，不能将新旧差异全部归因于响应损失。
O1–O0、E1–E0 才是相应上限下新增响应监督的控制比较。

网络层数、宽度 128、空间编码、归一化、门控 sigma=0.02 m、固定边界和独立速度头不变。
每组 2000 次 Adam 更新，学习率 0.001 / 原余弦调度、batch16、梯度裁剪1、反向损失乘100。
三路 minibatch 预先生成，四组共享同一份采样序列。

```text
L = L_ordinary + L_branch_absolute + response_enabled * L_pair_initial
```

位置单位 0.001 m、速度单位 0.1 m/s，位置 / 速度与活动 / ROI 权重均沿用 0.5。
相邻帧绝对监督使用各分支的真实当前 x / v，下一帧只作标签；
成对监督两次前向只接收初始当前条件，目标是下一帧 x / v 的响应差。
两者都使用当前原生几何 / 原生力作为调试条件，不训练解析力参数。

**内部与接触支路均更新。** 脱离时接触门控关闭，固定内部支路会阻止学习更强的无接触恢复；
因此本次记录了这个训练范围选择，没有把它描述成仅更新接触支路。

每 50 步及第 0 步，四组用同一公共验证目标选模：
`L_validation_ordinary + L_validation_branch_absolute + L_validation_pair_initial`。
O0 / E0 虽不对成对项求梯度，也用同一选模规则。没有按多步评价重选权重。
成对损失也改变了初始帧的重要性与误差耦合，不能将收益只归因于某种因果结构。

## 物理有效性失败：没有从指标中删掉

没有数值非有限值或预测异常窗口，固定位置、速度、增量仍严格满足边界。
但 **E1** 出现以下网格翻转：

- 普通轨迹左深第110帧窗口，M 条件的第 **14,15,16,17,18,20** 步发生翻转，
  共 **6 个记录状态**，最低体积比 **-0.518613**。
- 干预评价中，E1 的 7 个起点 / 条件窗口共 **31 个记录状态**翻转；
  其他四个模型及 CV 没有观察到这类翻转。

这些计数有共同起点 / base 的重复，不是 37 个独立实验。
表中 E1 指标包含这些状态，**E1 不通过网格有效性检查**，不能作为可靠动力学模型。
`physical_validity.json` 明确记录为 false；运行完成和数组有限不代表物理有效性通过。

## 结论、解释与下一优先项

**实测：**

1. 中央独立分支数据使接触响应更可学；绝对监督本身已将方向负值降到3项。
2. 输出上限确实限制了部分训练标签。扩大组一步幅度更接近参照，但不能据此认为自由多步更稳定。
3. 本轮响应损失的额外收益有限：未继续减少负方向数量，E1 的速度与网格有效性明显退化。
4. 模型尚未通过小速度干预和完整多步动力学验证；不能宣称学会通用物理接触或跨位置泛化。

**尚未验证的解释：**大扰动平方误差可能压过小速度信号；当前状态映射的独立位置 / 速度头
与一步选模目标，也可能不足以约束长期速度和局部网格形状。
这些是下一轮假设，不把它们写成已确定的唯一原因。

**下一轮唯一优先项是自由递推中的位置—瞬时速度联合稳定性与网格有效性。**
先利用已有二十步分支标签检验 / 约束这一点，并保留小速度干预指标；
本轮不再扩大数据、搜索更多上限或根据左侧多步分数重选检查点。
