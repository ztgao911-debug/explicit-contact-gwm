# 固定 8 帧对的损失尺度复核

日期：2026-10-15。本轮在原 Mac / CPU 环境实际完成损失 ×1、×100 两组训练。
**×100 的有限改善在原 8 帧对上仍然存在，但未达到预设的小样本拟合标准。**
本轮没有训练或评估验证 / 测试轨迹，也没有扩大数据。

## 这一步的目的与固定条件

单帧实验中 ×100 带来了改善；本轮检查同时拟合多个训练帧时，该改善能否保持。
这仍是对同一批被训练样本的拟合检查，不能解释为未见帧或未见轨迹上的泛化。

配置为 `configs/diagnose_soft_eight_pair_loss_scale.yaml`，复用已有损失尺度入口。
继承最初的 8 帧对配置 `diagnose_soft_residual.yaml`，不改变原训练配置。

固定样本与原 `outputs/soft_residual_diagnostics/run_001/fixed_samples.json` 精确一致：

| 轨迹 | 按压帧 / 当前时间 s | 保持帧 / 当前时间 s |
| --- | --- | --- |
| center_deep | 71 / 0.71，89 / 0.89 | 110 / 1.10，128 / 1.28 |
| center_shallow | 76 / 0.76，91 / 0.91 | 110 / 1.10，128 / 1.28 |

样本仍按各轨迹、各阶段的时间顺序分位点选择，不按标签或误差重新挑帧。
仅加载两条中央轨迹和共享网格；配置中原有的左侧验证名单只是元数据，本轮没有加载其数组。

两组均使用原两层 128 维 SiLU MLP、22022 个参数、相同种子 7 和零输出层，
输出上限 0.001 m、归一化、当前 MuJoCo 接触与力条件、固定节点约束均不变。
每帧 105 个活动节点、35 个固定节点；8 帧对共 840 个活动节点帧、257 个接触邻域节点帧。
`dt=0.01 s`，不使用未来状态作输入，不更新自由刚体。

两组分别从零训练 **2000 次更新**，每次使用相同完整 8 对；
Adam 学习率 0.001、余弦衰减至 1%、裁剪阈值 1、`betas=(0.9,0.999)`、`eps=1e-8` 一致。
只将原加权坐标 MSE 乘以 1 或 100，不改变活动节点 / 邻域各 0.5 的权重。
×100 等价于把损失单位从 0.001 m 改为 0.0001 m，物理输入和标签不变。

每组按同一 8 对的最低**未放大公共损失**保存权重，包含第 0 步，平局取更早步骤。
沿用原 8 对标准：活动节点和接触邻域 RMSE **均比恒速降低至少 50%**。
没有改用单帧实验的 90% 标准，也没有用验证 / 测试误差选模。

## 总体实测结果

单位为 **μm**，指标是三维增量向量 RMSE，而非单坐标 RMSE。

| 方法 | 活动节点 RMSE | 接触邻域 RMSE | 比恒速下降：活动 / 邻域 |
| --- | ---: | ---: | ---: |
| 恒速基线 | 3.47989 | 2.44970 | — |
| 原损失 ×1 | 3.16566 | 1.85444 | 9.03% / 24.30% |
| 损失 ×100 | **2.92882** | **1.58833** | **15.84% / 35.16%** |

相对 ×1，×100 的活动节点误差下降 **7.48%**，接触邻域误差下降 **14.35%**。
两组都没有触发梯度裁剪，因此本轮差异不涉及裁剪是否启动。
两组最优权重均在第 2000 步，公共损失分别为 `2.243391e-6`、`1.850126e-6`。
训练与逐步评估耗时分别约 **6.64 s、6.74 s**。

**预期与实测**：原 ×1 应复现已有结果；这一点通过全部逐步损失和权重的精确比较确认。
若单帧的数值尺度改善能保持，×100 应降低这批多帧误差；实测确实降低，
但两类误差均未达到 50% 降幅标准，不能称为已解决拟合不足。

## 按压与保持阶段

每个阶段均为 4 帧对、420 个活动节点帧；接触邻域分别有 113、144 个节点帧。

| 阶段 | 方法 | 活动节点 RMSE μm | 接触邻域 RMSE μm |
| --- | --- | ---: | ---: |
| 按压 | 恒速 | 4.70910 | 3.49348 |
| 按压 | ×1 | 4.26964 | 2.48156 |
| 按压 | ×100 | **3.92977** | **2.09378** |
| 保持 | 恒速 | 1.42954 | 1.06449 |
| 保持 | ×1 | 1.34648 | 1.14242 |
| 保持 | ×100 | **1.30877** | **1.03068** |

×100 在两个阶段都优于 ×1。保持阶段接触邻域由略差于恒速变为略好于恒速，
改善仍只是在这 4 个被拟合的保持帧对上观察到。
总体 RMSE 按节点帧误差平方汇总，不直接平均两个阶段的 RMSE。

## 复现与结论范围

需要现有 `pilot_001` 和最初的 `outputs/soft_residual_diagnostics/run_001/` 作为参照。
已有目录拒绝覆盖，重跑应指定新的输出目录：

```bash
source .venv/bin/activate
python scripts/diagnose_soft_loss_scale.py \
  --config configs/diagnose_soft_eight_pair_loss_scale.yaml \
  --output-dir outputs/soft_eight_pair_loss_scale/repeat_001
python scripts/diagnose_soft_loss_scale.py \
  --verify-only outputs/soft_eight_pair_loss_scale/repeat_001
python -m pytest
```

×100 可以保留为后续实验候选，但本轮没有覆盖完整训练轨迹、未见帧、验证 / 测试轨迹，
也没有把拟合成绩称为泛化。原正式训练配置没有被替换。
下一步建议检查多节点空间特征表达；目前证据仍不足以确定共享网络拟合不足的唯一原因。
