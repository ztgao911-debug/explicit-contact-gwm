# 冻结联合状态模型的接触机制审计

实验日期：**2026-10-27**，已在当前 Mac / CPU 实际完成。
输出：`outputs/contact_mechanism_audit/run_001/`。

**结论：已有有限预测收益，但尚无可靠的接触干预响应证据。**
高斯几何漏掉大部分接触；即使提供真实当前几何和力，局部网络对这批干预的响应仍有明显错误。
这两项是独立局限，不能用总体 RMSE 改善掩盖，也不能把全部失败都归因于解析力。

## 目标、模型与数据

本轮回到[原始研究目标](research-objectives-and-validation.md)：
同时检查接触机制是否正确，以及显式接触信息是否有实际预测价值。
没有继续训练固定恢复窗口，参数更新 **0**。

使用完整轨迹训练的 `joint_state_recovery/run_001/autonomous_joint/checkpoint.pt`：
**45324 参数，第 100 次更新选中，中央 600 对训练、左侧 600 对验证选模**。
它的接触分支得到过训练，与近期只拟合无接触恢复片段的 B 模型不同。
本轮没有重选权重。真实条件下全部 1500 对单步预测逐位复现历史完整模型。

加载中央浅 / 深、左侧浅 / 深和无接触对照，共五条、各 301 状态。
全部 **1500 对 / 方法**参与单步评价；每方法 30 个固定窗口，各自由递推 20 步，
提取 5 / 10 / 20 步指标，覆盖接近、按压、保持、卸载、脱离和恢复。
右侧数组未加载；左侧已用于历史选模和本次审计，不是未触碰的盲测集。

每节点一个 Gaussian，中心随节点状态，尺度为静止最近邻距的一半 **0.005 m**，旋转固定。
底部 **35** 个节点固定，活动节点 **105** 个；单步 ROI 使用相同参考接触邻域，
脱离后延续最后 ROI，rollout 固定起始 ROI，半径 0.02 m。
ROI 只评分，不输入任何预测器。

## 五个比较条件

| 方法 | 当前几何 | 当前力 | 状态更新 |
| --- | --- | --- | --- |
| M / `mujoco_force` | 当前预测状态重建的原生几何 | 当前原生求解力 | 冻结联合状态网络 |
| F / `analytic_force` | 与 M 完全相同 | 解析力 | 相同网络 |
| G / `gaussian_geometry` | 当前 Gaussian 几何 | 相同解析力 | 相同网络 |
| I / `internal_only` | 删除接触输入 | 删除接触输入 | 同一网络保留内部动力学支路 |
| CV / `constant_velocity` | 不需要 | 不需要 | 恒速、固定边界 |

I 是冻结模型的输入消融，可能分布外；它不是另行训练的同容量无接触模型。
I 保留位置、速度、静止编码等内部状态，不能与 CV 混为一谈。

所有方法从相同软体状态开始，使用相同已知外部压头输入。
初始化后只递推自身软体位置 / 瞬时速度，接触从当前预测状态重新计算，不回填软体真值。
位置与速度有独立输出，未用位移除以 dt 冒充瞬时速度；固定节点总增量、速度为零，位置为 rest。
本轮是**给定压头轨迹的软体预测**，不评价机器人闭环控制。

解析参数复用已有、仅由中央按压 / 保持标定的结果：
`k=691.386733 N/m`、`c=0 N·s/m`，切向阻尼 4 N·s/m、摩擦系数 0.3。
没有用左侧干预重新标定，没有把杨氏模量 5000 Pa 直接作接触刚度。
世界坐标、压头指向软体的法向、`v_robot-v_soft_contact`、N 和 N·m 口径均沿用已核对管线。
力矩参考当前动态质心，仅诊断，不把合力用于固定软块的自由刚体更新。

## 实测一：接触几何与力近似

左侧 600 帧中的 183 帧有受力接触。几何与受力帧两种检测口径本批结果相同：

| M | 100% | 0 / 0 | 1.82e-16 | 3.29e-16 |
| F | 100% | 0 / 0 | 0.07922 | 0.14345 |
| G | **7.65%（14/183）** | 0 / **169** | 0.10491 | 0.18997 |
| 全零力参照 | — | — | — | **0.19004** |

F 的力误差仍然显著；G 的接触帧合力误差几乎等于全零力参照。
M 的当前原生力与独立保存标签一致，力参考和坐标转换没有出现可见的系统偏差。

这是**匹配帧条件指标**，不能代表全部帧几何准确：绝大多数真接触被漏掉。
当前 0.001 m 等值面半径的稀疏节点球未填满软块表面，皮肤半径一致不等于接触表面等价。

## 独立物理干预：实际执行的方法与边界

预先固定 `left_deep` 第 **70、110、150** 帧，初始状态分别属于按压、保持、释放。
每个状态执行 6 个分支，共 **18 条**独立 MuJoCo 轨迹：

| 分支 | 压头位置初始偏移，m | 初始速度偏移，m/s |
| --- | --- | --- |
| base | 0 | 0 |
| detach | z +0.006 | 0 |
| shift_left | x -0.006 | 0 |
| shift_right | x +0.006 | 0 |
| deeper | z -0.001 | 0 |
| faster_down | 0 | z -0.01 |

每条只恢复一次该帧完整原生积分状态，**所有分支软体初始位置 / 速度逐位相同**。
只改变压头初始条件，位置偏移也作用于位置伺服目标；随后目标恒定，目标速度为零。
所有分支（包括 base）的初始 `qacc_warmstart` 都置零，防止特权的旧约束热启动。
这是假设不同压头初始条件的分支实验，不是机器人在实际轨迹中瞬移的控制实验。

尤其要注意：base 从当前命令开始保持，因此按压 / 释放起点的后续压头指令
**不同于原始完整轨迹未来指令**。新参照全部由求解器独立积分，不能直接套原轨迹未来标签。
每条积分 20 个记录步，原生步长 0.0002 s，记录 dt=0.01 s；另重复一条 base，
总计 **19000 个**原生内部积分步。

各方法只读取相同软体初始状态与该分支已实现的当前压头位置、速度和恒定指令。
软体连续自回归，不回填原生软体位置、速度、接触或力。
因此仍是给定压头轨迹的软体预测，未证明机器人—软体闭环预测。
M 使用从自己当前软体预测重建的当前原生接触 / 力，F/G 前向不接触真实力标签。

每个起点的干预 ROI 取所有分支**初始**原生接触邻域与原参考 ROI 的并集，去掉固定节点。
该掩码对全部方法和分支相同，仅用于评分，没有用未来形变挑选节点。

### 区分绝对状态误差与接触响应误差

```text
真实响应 = native_variant(h) - native_base(h)
预测响应 = model_variant(h) - model_base(h)
响应误差 = 预测响应 - 真实响应
```

这能剔除每种方法自身 base 的直接预测偏差。第一步从完全相同的软体当前状态出发，
更适合检查接触分支的响应；后续还包含模型状态漂移和接触重算的累积影响。
CV 与 I 在各分支的软体预测逐位相同，所以**干预响应为零**；
这不表示 I 的绝对预测状态等于 CV。
保存有单位向量 RMSE、预测 / 真实响应幅度、有符号投影增益和方向余弦，不能只比较幅值。

## 证据、解释和下一轮唯一优先项

**已有证据：**普通验证轨迹上存在有限接触信息收益和内部动力学收益；
高斯接触漏检严重；解析力存在明显误差；真实条件下的这批干预仍未表现正确响应。
本轮没有验证模型“理解物理接触”，也没有证明显式接触结构无价值。

**尚未验证的解释：**训练接触覆盖不足、接触支路学成对内部支路的补偿、
输入替换的分布变化或状态转移表达不足，都可能参与干预失败，尚未分离。
只有三种初始状态、单一材料与网格，位置分支有较大条件变化；左侧不是最终独立测试。

**下一轮只优先修正高斯接触表面覆盖。**
先在已知软块 / 球体几何上独立扫描接触与脱离，检验表面间隙、法向、召回和误报，
解决稀疏节点球不能覆盖连续表面的确定性问题，再将修正接回冻结模型复核。
目标是几何正确性，不是单独调大半径以改善某项状态分数。
真实条件下的网络干预失败继续作为独立未解问题保留；修复几何不保证它自动消失。
