# 高斯接触表面修复：方法选择与小型几何检查

日期：**2026-10-27**。本页保留方法选择时的三个静态查询、解析估算和原始方案。
后续已实际实现并运行[接触表面增密验证](contact-surface-validation.md)：
左侧召回 7.65% → 93.99%，释放仍漏检、部分法向指标退化，尚未完全修复。
下文“待实现”描述属于原方案，实际实现和运行结果以上述实验记录为准。

## 建议的第一版修复

先做**接触用表面代理高斯增密**，原 140 个动力学节点、编号、质量、监督与网络结构保留。
在节点之间的表面空隙补充查询用代理，而不是直接分裂现有动力学高斯并改变自由度。
先单独评价几何，不以网络状态 RMSE 选择密度。

## 代码现状与实测

当前有 140 个节点，其中 110 个表面节点，静止顶面 35 个节点。
最近邻间距为 **10 mm**，高斯尺度 **5 mm**，接触等值面倍数 **0.2**，
所以碰撞形状是表面节点处半径 **1 mm** 的离散小球。
高斯本身虽然有无限支撑，但当前碰撞判断只使用这个有限等值面。

实际调用已有 `NativeCurrentContact.query(with_force=False)` 和 `gaussian_contacts`，
静止软块顶面 z=30 mm，压头半径 12 mm、中心 z=42.9 mm，
相对包含 1 mm 碰撞皮肤的平面压入 **0.1 mm**：

| 压头 XY，mm | 原生几何接触数 | 当前高斯接触数 |
| --- | ---: | ---: |
| (0, 0)，节点上方 | 6 | 1 |
| (5, 5)，单元中心 | 2 | **0** |
| (2.5, 2.5)，节点之间 | 1 | **0** |

这是三个静态点的实际查询，不是修复后的性能结果，也不取代全场景扫描。
它支持“节点间覆盖不足”这一具体原因，而非只凭 7.65% 的轨迹召回率猜测。

## 为什么加密有作用：解析估算

在无限平面、规则方格采样、等半径小球、球形压头的简化条件下，
单元中心最远离节点，横向距离为 `d=a/sqrt(2)`。
设压头半径 R=12 mm，碰撞皮肤 r=1 mm，则离散表示相对连续平面的接触起始延迟为：

```text
bias = (R+r) - sqrt((R+r)^2 - a^2/2)
```

| 表面采样间距 a | 最坏起始接触延迟 |
| --- | ---: |
| 10 mm，当前 | 2.091 mm |
| 5 mm | 0.490 mm |
| 2.5 mm | 0.121 mm |
| 2 mm | 0.077 mm |

因此可以先预设 **2 mm 接触代理间距**作几何小试。
这些是简化平面的解析结果，尚未验证变形表面、边缘、角点或新实现的轨迹召回。
即使增密，有限球样本仍近似连续表面；误差容限必须明确，不能要求无限精确。

## 几个选项的区别

| 选项 | 判断 | 原因与条件 |
| --- | --- | --- |
| 加密仿真网格 / 增加动力学节点 | 本轮不选 | 改变求解分辨率、状态规模和监督，难隔离几何修复收益 |
| 直接分裂已有小球并缩小尺度 | 不能单独作为修复 | 可能仍集中在原位置附近，不保证填补表面空隙 |
| 全部球等比例放大 | 仅可作诊断对照 | 同时改变法向厚度和物体边界，可能提前接触、误报、偏置穿透 |
| 表面空隙补接触代理、保持物理皮肤厚度 | **第一版选择** | 可控地检查采样误差，动力学状态维度保留 |
| 表面对齐的各向异性高斯 / 定向面元 | 后续表示对照 | 可用较少元素铺开切向覆盖，但需处理法向、边缘、形变更新与正确距离查询 |
| 由高斯构造连续隐式表面 | 长期候选 | 需定义物理等值面、内外和米制距离；高斯密度值不是 SDF 或直接的米制穿透 |

[原始 3DGS](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/3d_gaussian_splatting_low.pdf)
的克隆 / 分裂用于重建与渲染优化，不能把视觉增密规则直接当作接触几何验收。
[2DGS](https://surfsplatting.github.io/)提供定向 Gaussian 面元的表示思路，
但不是本项目现成的物理碰撞实现。

当前 `compute_gaussian_contacts` 只沿两中心连线计算支持面间隙。
对当前各向同性球它是准确的球间距；改成各向异性后，这只是一个投影方向，
不能当作精确椭球距离。因此各向异性方案必须同步验证 / 修正最近点或分离查询，
不能只修改 scale 和 rotation 后宣称解决。

## 代理如何随软体更新

第一版可以利用已知初始表面拓扑，为代理记录节点插值权重：

```text
proxy_position(t) = sum_i w_i * current_node_position_i(t)
proxy_velocity(t) = sum_i w_i * current_node_velocity_i(t)
sum_i w_i = 1
```

权重来自初始绑定，更新只读当前预测节点状态；代理不增加独立质量或学习状态。
该版本依赖已知拓扑，是有拓扑绑定的 Gaussian 接触代理，应明确报告这个假设。
它不查询当前 MuJoCo 表面或未来真值，但也不证明无拓扑的纯 Gaussian 表面问题已解决。

## 接入力之前必须处理的变化

增加采样点会改变接触候选数。现有 `k*penetration` 按候选逐点计算，合力直接求和；
网络又对候选力做归一化平均。这两种聚合都需要检查密度依赖。

应明确接触簇合并或面积积分权重，使同一物理接触在代理更密时不会被重复计力。
原来以 N/m 标定的每候选刚度不能直接无修改地复制到新增代理。
若改为单位面积接触模型，刚度单位、标定和网络输入口径也要随之明确。
力标定仍仅用中央训练轨迹，不能用左侧召回率或状态误差调力掩盖几何误差。

## 下一步几何验收

比较原代理与预定密度的代理，扫描节点上方、节点之间、边缘 / 角点，
包含分离、临界、浅压入，以及已有代表性变形表面。
先报告召回、误报、接触起始误差、间隙与法向误差、代理数及耗时。
几何通过后，再分开验证合力的密度收敛和冻结网络的输入变化。
几何修复也不会自动解决上一轮真实几何 / 力条件下的神经网络干预失败。
