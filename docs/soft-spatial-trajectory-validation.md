# 空间编码：完整轨迹训练与左侧验证

日期：2026-10-15。基于提交 `9fc7726` 的 A/B/C 实现，在独立分支推进。

## 预先固定的协议

- 中央浅/深两条完整轨迹划为训练，左侧浅/深两条划为验证。
- 各集合使用全部 149 个合格相邻帧对，仍只包含当前有接触的按压/保持阶段。
- A：原 MLP（128，22022 参数）；B：静止坐标固定编码（128，24326 参数）；
  C：原输入容量对照（135，24171 参数），直接复用 `spatial_ablation.py`。
- 种子固定为 7、17、27，共九次从头训练；各组相同种子的批次顺序一致。
- 沿用 500 epoch、batch 16、Adam lr=0.001、余弦衰减至 1%、梯度裁剪阈值 1；
  只将反向传播目标乘 100。公共物理误差和选模损失不放大。
- 包含第0轮恒速候选，按左侧验证公共加权坐标 MSE 选模，平局选更早 epoch。
- 所有最终区域/阶段指标均使用同一个验证选定权重，不分别挑选最好的阶段。
- 另存最后一轮的训练集指标，作为拟合诊断；不将它当作验证选定结果。
- 不加载右侧测试轨迹数组，不进行自由多步预测；仍提供真实当前状态、接触和力。

数据由 MuJoCo 3.3.7 按原配置重新采集，7条轨迹通过回放校验。当前训练/验证
只读取四条中央/左侧数组。保护检查会读取数据文件的哈希字节，右侧数组不进入训练或评价。

## 结果

已实际完成九次 CPU 训练。单位均为三维增量向量 RMSE，μm。网络报告三个种子的均值 ± 样本标准差；恒速只计算一次。

| 方法 | 活动节点 | 接触邻域 |
| --- | ---: | ---: |
| 恒速 | 4.29420 | 4.78905 |
| A：原MLP | 4.19677 ± 0.00027 | 4.57122 ± 0.00162 |
| B：空间编码 | 4.24913 ± 0.00984 | 4.68083 ± 0.01987 |
| C：容量对照 | 4.20676 ± 0.01041 | 4.58430 ± 0.02237 |

A 相对恒速的总体活动/邻域误差降低约 **2.27% / 4.55%**；B 降低约 **1.05% / 2.26%**。
B 的两个总体验证指标在三个种子中均未超过 A 或 C，固定8帧对上的排序没有迁移到左侧验证。

### 当前输入的额外检查

- 原始36维上下文的第20号通道（0起算）是压头目标横坐标，归一化尺度0.05m。训练范围 `[0.0, 0.0]`，左侧验证范围 `[-0.3999999761581421, -0.3999999761581421]`。
- 九个验证选定模型中，该通道对应的第一层连接权重与各自初始化完全相同，最大变化均为0。训练输入恒为0，与这些权重未获得训练一致。
- 这是已观察到的输入分布差异，**尚未证明它造成了全部验证差距**。下一步可保持A/B/C、数据与预算不变，仅将压头位置改为相对节点的位置作单因素对照。

## 结论范围

三个种子的标准差只反映固定数据上的初始化/优化波动，并不覆盖不同对象、
材料或按压位置的总体不确定性。左侧是反复用于选模的验证集，收益不能当作
最终独立测试结论。正式确认应使用新增且预先保留的独立轨迹。
